Статус интеграции

Godot Web Editor требует экспортированных WASM-файлов от Godot Engine 4.3+. Интеграция запланирована на Sprint 8 (iframe + PostMessage API).

  1. Экспортировать Godot Editor как Web-приложение
  2. Разместить .wasm, .js, .data файлы в Docker volume
  3. Настроить COOP/COEP заголовки (готово в Nginx)
  4. Реализовать PostMessage API для связи iframe ↔ платформа

Docker + Nginx + S3 инфраструктура уже настроена (Sprint 7).
Эта страница обслуживается с COOP/COEP заголовками.
