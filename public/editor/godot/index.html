Редактор недоступен

Файлы Godot Editor WASM не найдены на сервере. Для работы редактора необходимо развернуть Docker-окружение с экспортированными файлами Godot.

Как настроить окружение:

  1. Экспортируйте Godot Editor как Web-приложение (Godot 4.3+)
  2. Поместите файлы godot-editor.js, godot-editor.wasm, godot-editor.data в Docker volume
  3. Убедитесь, что Nginx обслуживает файлы с COOP/COEP заголовками
  4. Перезапустите Docker-контейнер: docker compose restart godot-editor

PostMessage API работает даже в режиме placeholder — платформа может обмениваться сообщениями с этой страницей.
