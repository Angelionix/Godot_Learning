# Tower Defense

Стартовый шаблон для создания Tower Defense на Godot Engine 4.3+.

## Описание

Этот шаблон предназначен для создания игры в жанре «Tower Defense» — размещайте башни на карте, чтобы остановить волны врагов, идущих по заданному пути.

## Что включено

- Базовая сцена `main.tscn` с корневым узлом `Node2D`
- Настроенный проект с разрешением 1280×720
- Рендерер: OpenGL Compatibility (оптимально для 2D)

## Рекомендуемая структура проекта

```
res://
├── scenes/
│   ├── main.tscn          # Главная сцена
│   ├── map.tscn           # Сцена карты
│   ├── towers/            # Сцены башен
│   ├── enemies/           # Сцены врагов
│   └── projectiles/       # Сцены снарядов
├── scripts/
│   ├── game_manager.gd    # Управление игрой
│   ├── tower.gd           # Базовый скрипт башни
│   ├── enemy.gd           # Базовый скрипт врага
│   ├── wave_manager.gd    # Управление волнами
│   └── path.gd            # Путь движения врагов
├── assets/
│   ├── sprites/           # Спрайты и тайлсеты
│   └── audio/             # Звуковые эффекты
└── project.godot
```
