```
tests/

```

## Фреймворк

Тесты написаны с использованием **GUT 9.x** для **Godot 4.x**.

Все тестовые скрипты наследуются от `GutTest` и используют встроенные утверждения:

| Утверждение         | Описание                              |
|---------------------|---------------------------------------|
| `assert_true()`     | Проверяет, что значение `true`        |
| `assert_eq()`       | Проверяет равенство двух значений     |
| `assert_ne()`       | Проверяет неравенство двух значений   |
| `assert_gt()`       | Проверяет, что первое > второго       |
| `assert_lt()`       | Проверяет, что первое < второго       |
| `assert_not_null()` | Проверяет, что значение не `null`     |
| `assert_false()`    | Проверяет, что значение `false`       |

## Список тестов

| Тест                          | Что проверяет                                    |
|-------------------------------|--------------------------------------------------|
| `test_enemy_follows_path`     | Враг движется по предопределённому маршруту      |
| `test_tower_targets_enemy`    | Башня нацеливается на ближайшего врага           |
| `test_tower_shoots_projectile`| Башня стреляет снарядом при наличии цели         |
| `test_projectile_hits_enemy`  | Снаряд наносит урон при столкновении             |
| `test_enemy_takes_damage`     | Враг получает урон и может погибнуть             |
| `test_gold_increments_on_kill`| Золото увеличивается при убийстве врага          |
| `test_tower_placement_on_tile`| Башню можно разместить только на допустимом тайле|
| `test_wave_spawns_enemies`    | Волна спавнит заданное количество врагов         |

## Запуск тестов

1. Установите GUT: https://github.com/bitwes/Gut
2. Скопируйте `.gutconfig.json` из `shared/` в корень проекта
3. Запустите через командную строку:
   ```bash
   godot --path . -s addons/gut/gut_cmdln.gd
   ```
   Или через редактор: сцена `addons/gut/GutScene.tscn`

## Зависимые скрипты

Для работы тестов (без заглушек) необходимо реализовать:

- `res://scripts/enemy.gd` — поведение врага (здоровье, смерть)
- `res://scripts/tower.gd` — башня (цели, стрельба, радиус)
- `res://scripts/projectile.gd` — снаряд (урон, столкновение)
- `res://scripts/enemy_path_follow.gd` — движение врага по пути
- `res://scripts/wave_manager.gd` — управление волнами
- `res://scripts/gold_manager.gd` — управление золотом
- `res://scripts/build_grid.gd` — сетка для размещения башен

## Примечание

Все тесты содержат **заглушки** (assert_true(true)) и закомментированные реальные проверки.
После реализации соответствующих скриптов раскомментируйте тесты и удалите заглушки.
