# Тесты проекта «Космический шутер»

## Структура

```
tests/
├── README.md              — Этот файл
└── test_space_shooter.gd  — Тесты космического шутера
```

## Фреймворк

Тесты написаны с использованием **GUT 9.x** для **Godot 4.x**.

Все тестовые скрипты наследуются от `GutTest` и используют встроенные утверждения:

| Утверждение         | Описание                              |
|---------------------|---------------------------------------|
| `assert_true()`     | Проверяет, что значение `true`        |
| `assert_eq()`       | Проверяет равенство двух значений     |
| `assert_ne()`       | Проверяет неравенство двух значений   |
| `assert_lt()`       | Проверяет, что первое < второго       |
| `assert_gt()`       | Проверяет, что первое > второго       |
| `assert_not_null()` | Проверяет, что значение не `null`     |
| `assert_has_signal()`| Проверяет наличие сигнала у объекта   |

## Список тестов

| Тест                                | Что проверяет                                   |
|-------------------------------------|-------------------------------------------------|
| `test_player_moves_left_right`      | Игрок двигается влево и вправо                  |
| `test_player_shoots_bullet`         | Игрок стреляет снарядом                         |
| `test_bullet_moves_upward`          | Снаряд движется вверх                           |
| `test_enemy_spawns_at_top`          | Враг спавнится в верхней части экрана           |
| `test_collision_destroys_enemy`     | Столкновение снаряда уничтожает врага           |
| `test_score_increments_on_kill`     | Очки увеличиваются при уничтожении врага        |
| `test_player_dies_on_enemy_collision`| Игрок погибает при столкновении с врагом       |

## Запуск тестов

1. Установите GUT: https://github.com/bitwes/Gut
2. Скопируйте `.gutconfig.json` из `shared/` в корень проекта
3. Запустите через командную строку:
   ```bash
   godot --path . -s addons/gut/gut_cmdln.gd
   ```
   Или через редактор: сцена `addons/gut/GutScene.tscn`

## Зависимые скрипты

Для работы тестов (без заглушек) необходимо реализовать:

- `res://scripts/player.gd` — управление игроком
- `res://scripts/bullet.gd` — поведение снаряда
- `res://scripts/enemy.gd` — поведение врага
- `res://scripts/enemy_spawner.gd` — спавнер врагов
- `res://scripts/score_manager.gd` — подсчёт очков

## Примечание

Все тесты содержат **заглушки** (assert_true(true)) и закомментированные реальные проверки.
После реализации соответствующих скриптов раскомментируйте тесты и удалите заглушки.
