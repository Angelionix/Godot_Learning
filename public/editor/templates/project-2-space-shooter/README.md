# Космический шутер

Стартовый шаблон для создания космического шутера на Godot Engine 4.3+.

## Описание

Этот шаблон предназначен для создания аркадного космического шутера. Управляйте кораблём, уничтожайте врагов и уклоняйтесь от снарядов в бескрайнем космосе.

## Что включено

- Базовая сцена `main.tscn` с корневым узлом `Node2D`
- Настроенный проект с разрешением 1280×720
- Рендерер: OpenGL Compatibility (оптимально для 2D)

## Рекомендуемая структура проекта

```
res://
├── scenes/
│   ├── main.tscn          # Главная сцена
│   ├── player.tscn        # Сцена игрока
│   ├── enemy.tscn         # Сцена врага
│   ├── bullet.tscn        # Сцена снаряда
│   └── effects/           # Визуальные эффекты
├── scripts/
│   ├── player.gd          # Управление игроком
│   ├── enemy.gd           # ИИ врагов
│   ├── bullet.gd          # Логика снарядов
│   └── spawner.gd         # Спавн врагов
├── assets/
│   ├── sprites/           # Спрайты
│   └── audio/             # Звуковые эффекты
└── project.godot
```
