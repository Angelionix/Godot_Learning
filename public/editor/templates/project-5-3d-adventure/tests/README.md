# Тесты проекта «3D Приключение»

## Структура

```
tests/
├── README.md              — Этот файл
└── test_3d_adventure.gd   — Тесты 3D-приключения
```

## Фреймворк

Тесты написаны с использованием **GUT 9.x** для **Godot 4.x**.

Все тестовые скрипты наследуются от `GutTest` и используют встроенные утверждения:

| Утверждение         | Описание                              |
|---------------------|---------------------------------------|
| `assert_true()`     | Проверяет, что значение `true`        |
| `assert_false()`    | Проверяет, что значение `false`       |
| `assert_eq()`       | Проверяет равенство двух значений     |
| `assert_gt()`       | Проверяет, что первое > второго       |
| `assert_lt()`       | Проверяет, что первое < второго       |
| `assert_not_null()` | Проверяет, что значение не `null`     |

## Список тестов

| Тест                           | Что проверяет                                    |
|--------------------------------|--------------------------------------------------|
| `test_player_movement_3d`      | Движение игрока в 3D-пространстве (X, Z)        |
| `test_camera_follows_player`   | Камера плавно следует за игроком                 |
| `test_interactable_detection`  | Обнаружение взаимодействуемых объектов в радиусе |
| `test_inventory_add_item`      | Добавление предмета в инвентарь                  |
| `test_inventory_remove_item`   | Удаление предмета из инвентаря                   |
| `test_door_opens_with_key`     | Дверь открывается только с правильным ключом     |
| `test_npc_dialogue_trigger`    | Диалог с NPC активируется при взаимодействии     |

## Запуск тестов

1. Установите GUT: https://github.com/bitwes/Gut
2. Скопируйте `.gutconfig.json` из `shared/` в корень проекта
3. Запустите через командную строку:
   ```bash
   godot --path . -s addons/gut/gut_cmdln.gd
   ```
   Или через редактор: сцена `addons/gut/GutScene.tscn`

## Зависимые скрипты

Для работы тестов (без заглушек) необходимо реализовать:

- `res://scripts/player.gd` — игрок (CharacterBody3D)
- `res://scripts/camera_controller.gd` — следящая камера
- `res://scripts/interactable.gd` — взаимодействуемые объекты
- `res://scripts/inventory.gd` — инвентарь игрока
- `res://scripts/door.gd` — двери с требованиями ключей
- `res://scripts/npc.gd` — неигровые персонажи
- `res://scripts/dialogue_manager.gd` — управление диалогами

## Примечание

Все тесты содержат **заглушки** (assert_true(true)) и закомментированные реальные проверки.
После реализации соответствующих скриптов раскомментируйте тесты и удалите заглушки.
