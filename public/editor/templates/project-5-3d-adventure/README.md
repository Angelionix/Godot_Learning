# 3D Приключение

Стартовый шаблон для создания 3D-приключенческой игры на Godot Engine 4.3+.

## Описание

Этот шаблон предназначен для создания 3D-игры в жанре «приключение». Исследуйте трёхмерный мир, взаимодействуйте с объектами и раскрывайте тайны.

## Что включено

- Базовая сцена `main.tscn` с корневым узлом `Node3D`
- Настроенный проект с разрешением 1280×720
- Рендерер: Forward+ (оптимально для 3D)

## Рекомендуемая структура проекта

```
res://
├── scenes/
│   ├── main.tscn          # Главная сцена
│   ├── player.tscn        # Сцена игрока
│   ├── world/             # Сцены окружения
│   ├── interactables/     # Интерактивные объекты
│   └── ui/                # Интерфейс
├── scripts/
│   ├── player.gd          # Управление игроком
│   ├── camera.gd          # Управление камерой
│   ├── interactable.gd    # Взаимодействие с объектами
│   └── inventory.gd       # Система инвентаря
├── assets/
│   ├── models/            # 3D-модели
│   ├── textures/          # Текстуры
│   └── audio/             # Звуки и музыка
└── project.godot
```
