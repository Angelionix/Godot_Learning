# Тесты проекта «Метроидвания»

## Структура

```
tests/
├── README.md              — Этот файл
└── test_metroidvania.gd   — Тесты метроидвании
```

## Фреймворк

Тесты написаны с использованием **GUT 9.x** для **Godot 4.x**.

Все тестовые скрипты наследуются от `GutTest` и используют встроенные утверждения:

| Утверждение         | Описание                              |
|---------------------|---------------------------------------|
| `assert_true()`     | Проверяет, что значение `true`        |
| `assert_eq()`       | Проверяет равенство двух значений     |
| `assert_ne()`       | Проверяет неравенство двух значений   |
| `assert_has_signal()`| Проверяет наличие сигнала у объекта   |

## Список тестов

| Тест                         | Что проверяет                                    |
|------------------------------|--------------------------------------------------|
| `test_player_idle_state`     | Состояние покоя игрока (Idle)                    |
| `test_player_run_state`      | Состояние бега игрока (Run)                      |
| `test_player_jump_state`     | Состояние прыжка игрока (Jump)                   |
| `test_player_attack_state`   | Состояние атаки игрока (Attack)                  |
| `test_state_transition`      | Переходы между состояниями конечного автомата    |
| `test_health_system`         | Система здоровья (урон, лечение, смерть)         |
| `test_collectible_pickup`    | Подбор предметов и добавление в инвентарь        |
| `test_door_unlock_requires_key` | Дверь открывается только с ключом             |

## Запуск тестов

1. Установите GUT: https://github.com/bitwes/Gut
2. Скопируйте `.gutconfig.json` из `shared/` в корень проекта
3. Запустите через командную строку:
   ```bash
   godot --path . -s addons/gut/gut_cmdln.gd
   ```
   Или через редактор: сцена `addons/gut/GutScene.tscn`

## Зависимые скрипты

Для работы тестов (без заглушек) необходимо реализовать:

- `res://scripts/player.gd` — игрок (CharacterBody2D)
- `res://scripts/state_machine.gd` — конечный автомат состояний
- `res://scripts/health_system.gd` — система здоровья
- `res://scripts/collectible.gd` — подбираемые предметы
- `res://scripts/inventory.gd` — инвентарь игрока
- `res://scripts/door.gd` — двери с требованиями ключей

## Архитектура состояний

Конечный автомат (StateMachine) управляет следующими состояниями:

```
Idle ←→ Run ←→ Jump
  ↑         ↓
  └── Attack ┘
```

Каждое состояние должно иметь сигнал `state_finished` для возврата к Idle.

## Примечание

Все тесты содержат **заглушки** (assert_true(true)) и закомментированные реальные проверки.
После реализации соответствующих скриптов раскомментируйте тесты и удалите заглушки.
