# Метроидвания

Стартовый шаблон для создания метроидвании на Godot Engine 4.3+.

## Описание

Этот шаблон предназначен для создания игры в жанре «метроидвания» — исследуйте interconnected мир, находите новые способности и открывайте ранее недоступные области.

## Что включено

- Базовая сцена `main.tscn` с корневым узлом `Node2D`
- Настроенный проект с разрешением 1280×720
- Рендерер: OpenGL Compatibility (оптимально для 2D)

## Рекомендуемая структура проекта

```
res://
├── scenes/
│   ├── main.tscn          # Главная сцена
│   ├── player.tscn        # Сцена игрока
│   ├── maps/              # Карты уровней (TileMap)
│   ├── enemies/           # Сцены врагов
│   └── abilities/         # Сцены способностей
├── scripts/
│   ├── player.gd          # Управление игроком
│   ├── player_state.gd    # Конечный автомат игрока
│   ├── camera.gd          # Камера следования
│   └── world_state.gd     # Состояние мира
├── assets/
│   ├── sprites/           # Спрайты и тайлсеты
│   └── audio/             # Музыка и звуки
└── project.godot
```
