# Кликер / Idle-игра

Стартовый шаблон для создания кликер-игры (idle-игры) на Godot Engine 4.3+.

## Описание

Этот шаблон предназначен для создания игр жанра «кликер» или «idle». В таких играх игрок нажимает на объекты для получения ресурсов, которые затем можно тратить на улучшения и автоматизацию.

## Что включено

- Базовая сцена `main.tscn` с корневым узлом `Node2D`
- Настроенный проект с разрешением 1280×720
- Частота физики: 60 тиков/сек

## Рекомендуемая структура проекта

```
res://
├── scenes/
│   ├── main.tscn          # Главная сцена
│   ├── game.tscn          # Игровая сцена
│   └── upgrades/          # Сцены улучшений
├── scripts/
│   ├── game_manager.gd    # Управление игровой логикой
│   ├── click_handler.gd   # Обработка кликов
│   └── upgrade_system.gd  # Система улучшений
├── assets/
│   ├── sprites/           # Спрайты
│   └── audio/             # Звуковые эффекты
└── project.godot
```
