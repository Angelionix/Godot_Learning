# Performance Demo

Стартовый шаблон для демонстрации производительности на Godot Engine 4.3+.

## Описание

Этот шаблон предназначен для создания демо-проекта с акцентом на производительность и оптимизацию. Идеально подходит для изучения техник оптимизации 3D-рендеринга в Godot.

## Что включено

- Базовая сцена `main.tscn` с корневым узлом `Node3D`
- Настроенный проект с разрешением 1280×720
- Рендерер: Forward+ (оптимально для 3D)

## Рекомендуемая структура проекта

```
res://
├── scenes/
│   ├── main.tscn          # Главная сцена
│   ├── stress_test.tscn   # Сцена стресс-теста
│   ├── lod_demo.tscn      # Демо LOD
│   └── culling_demo.tscn  # Демо отсечения
├── scripts/
│   ├── performance_monitor.gd  # Мониторинг производительности
│   ├── spawner.gd              # Спавн объектов
│   └── profiler.gd             # Профилирование
├── assets/
│   ├── models/            # 3D-модели
│   ├── textures/          # Текстуры
│   └── materials/         # Материалы
└── project.godot
```

## Темы для изучения

- LOD (Level of Detail)
- Окклюзионное отсечение (Occlusion Culling)
- Батчинг и инстансинг
- Оптимизация материалов и шейдеров
- Профилирование с встроенными инструментами Godot
