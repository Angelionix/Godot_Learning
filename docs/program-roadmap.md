## Обзор

Дорожная карта разработки веб-приложения Godot Learning Platform. Разработка ведётся двумя фазами: MVP (базовая платформа) и Godot Web Editor (Pro-фичи). Фаза 3 (Cloud Workspaces) отложена.

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| GDScript WASM runtime нестабилен | Высокая | Высокое | Fallback на mock-выполнение (Variant C) |
| SharedArrayBuffer не работает в Safari | Средняя | Среднее | Чёткое предупреждение + fallback |
| Задержка с контентом (MDX конвертация) | Средняя | Высокое | Параллельная работа: контент + платформа |
| Monaco Editor замедляет загрузку | Низкая | Среднее | Dynamic import + skeleton loading |
| Превышение сроков | Средняя | Среднее | Приоритизация: MVP без геймификации > полный MVP с задержкой |
