# Правила версионирования

> Godot Learning Platform использует **Semantic Versioning 2.0.0** (SemVer)

---

## Формат версии

```
MAJOR.MINOR.PATCH
```

- **MAJOR** — несовместимые изменения API или архитектуры
- **MINOR** — новый функционал, обратно совместимый
- **PATCH** — исправления багов, обратно совместимые

---

## Где хранится версия

| Место | Формат | Назначение |
|-------|--------|------------|
| `package.json` → `version` | `"0.3.0"` | npm-экосистема, сборка |
| `VERSION` | `0.3.0` | Единый источник истины, читаемый файл |
| UI (sidebar footer) | `v0.3.0` | Отображение пользователю |

---

## Правила обновления версии

### PATCH (0.0.X)

Исправления багов и мелкие улучшения, не добавляющие новый функционал:

- Исправление форматирования контента
- Исправление CSS-багов (overflow, выравнивание)
- Обновление текста в MDX-файлах без изменения структуры
- Мелкие фиксы в UI-компонентах

### MINOR (0.X.0)

Новый функционал, обратно совместимый с предыдущими версиями:

- Добавление новой главы или раздела в курс
- Новый MDX-компонент (Callout, Insight и т.д.)
- Новый API-маршрут
- Новый UI-экран (дашборд, профиль)
- Добавление нового проекта курса (P2–P6)
- Интеграция новой библиотеки или сервиса

### MAJOR (X.0.0)

Несовместимые изменения, требующие миграции:

- Изменение схемы базы данных без обратной совместимости
- Реструктуризация URL-маршрутов
- Переход на другой фреймворк или архитектуру
- Удаление или замена существующего API

---

## Процесс релиза

1. Обновить версию в `package.json` и `VERSION`
2. Добавить запись в `CHANGELOG.md` (секция `[X.Y.Z] - YYYY-MM-DD`)
3. Закоммитить с сообщением: `chore: release vX.Y.Z`
4. Создать git-тег: `vX.Y.Z`

---

## Предрелизные версии

Пока проект находится в активной разработке (MAJOR = 0), API считается нестабильным. Любой MINOR-релиз может содержать несовместимые изменения. После стабилизации базового функционала ( Planned: v1.0.0) будет установлен мораторий на breaking changes в MINOR-релизах.

## Примеры

| Изменение | Тип | Пример |
|-----------|-----|--------|
| Исправлен баг с таблицами | PATCH | 0.3.0 → 0.3.1 |
| Добавлена глава «Шейдеры» | MINOR | 0.3.0 → 0.4.0 |
| Переработаны все MDX-файлы под новый формат | MINOR | 0.3.0 → 0.4.0 |
| Изменена структура URL /learn/ → /course/ | MAJOR | 0.3.0 → 1.0.0 |
| Добавлена аутентификация NextAuth | MINOR | 0.3.0 → 0.4.0 |
| Изменена схема БД (новые поля, старые удалены) | MAJOR | 0.3.0 → 1.0.0 |
