# Концепция курса: Проектный курс разработки игр на Godot Engine

> **Версия:** 1.0  
> **Дата:** 2026-06-02  
> **Статус:** Черновик  
> **Язык курса:** Русский

---

## 1. Видение

Создать **единственный на русском языке** комплексный проектный курс по разработке игр на Godot Engine, который проводит ученика от полного нуля до профессионального уровня с уникальным переходом от GDScript к C++ через GDExtension. Курс не просто учит «как нажать кнопку» — он формирует **архитектурное мышление**, позволяющее выпускнику самостоятельно создавать игры любой сложности.

## 2. Проблема

Существующие Godot-курсы страдают от набора системных проблем:

### 2.1. Tutorial Hell
Ученик может повторить за инструктором, но не способен создать свой проект с нуля. Это самая частая жалоба в Reddit-сообществе r/godot: *"I understand the process, but I can't make anything on my own."* Курс GamDev.tv, несмотря на название "Complete", оставляет учеников в состоянии, когда они не могут даже простенький jam-проект собрать самостоятельно.

### 2.2. Поверхностность
GameDev.tv "Complete Godot 4 Game Developer 2D" не покрывает: save/load, collision layers/masks, autoloads, шейдеры, публикацию, raycasting, pause-системы. Один из учеников написал: *"I feel like I just started the course, barely scratched the surface of the engine's abilities. And it's over."*

### 2.3. Отсутствие интерактивности
YouTube-туториалы (Brackeys, HeartBeast, Clear Code) — это пассивное потребление. Нет проверки знаний, нет прогресс-трекинга, нет обратной связи. Посмотрел → забыл.

### 2.4. Нет перехода к C++
Ни один существующий курс не покрывает GDExtension и C++. Для серьёзных проектов (высокая производительность, интеграция библиотек) это критический пробел.

### 2.5. Нет русскоязычного контента с глубиной
Русские курсы на Stepik и Coddyschool — поверхностные, только GDScript, только 2D, ориентированы на детей.

### 2.6. Устаревание
GDQuest — лучший по качеству контент, но Godot 3 курсы устарели, а Godot 4 курсы годами в Early Access. Контент не обновляется синхронно с движком.

## 3. Наше решение

### 3.1. Принцип «Понимай, а не копируй»
Каждый блок кода сопровождается разделом **«Почему это работает именно так?»**. После объяснения — **вариации**: «А что если изменить X на Y?» + **контрастные примеры**: как НЕ надо делать и почему.

### 3.2. Микро-челленджи между шагами
Небольшие самостоятельные задания с нарастающей сложностью после каждого раздела. Три уровня: 🟢 Базовый / 🟡 Продвинутый / 🔴 Экспертный. Аналог CodinGame, но встроенный в контекст конкретного проекта.

### 3.3. Финальный спринт — ТВОЙ проект
В конце каждого модуля — не копирование, а **самостоятельное расширение** по требованиям. Референсные решения доступны, но только после попытки.

### 3.4. Итеративное усложнение
Один и тот же проект развивается на протяжении нескольких глав: простая версия → добавление фич → рефакторинг → оптимизация. Ученик видит эволюцию, а не только финальный вариант.

### 3.5. Архитектурное мышление с первого дня
Диаграммы классов/UML перед кодом. Паттерны проектирования встроены в проекты, а не выделены в отдельную скучную тему. Раздел «Как это масштабируется?» в каждом проекте.

### 3.6. Уникальный GDScript → C++ переход
Единственный курс, который учит выносить критичный код в C++ через GDExtension. Реальные бенчмарки: тот же алгоритм на GDScript vs C++, замеры, анализ.

## 4. Структура курса

### Проект 1: Кликер / Idle Game (GDScript — основы)
**Язык:** Чистый GDScript  
**Сложность:** ⭐ (Начальная)  
**Результат:** Полноценная idle-игра с апгрейдами, достижениями, save/load

| Тема | Описание |
|------|----------|
| Переменные и типы | `int`, `float`, `String`, `bool`, `Array`, `Dictionary` |
| Функции | Параметры, возврат значений, рекурсия |
| Сигналы | Объявление, подключение, кастомные сигналы |
| UI-система | `Control`, `Label`, `Button`, `TextureProgressBar` |
| Save/Load | `JSON`, `FileAccess`, автосохранение |
| Достижения | Система условий, уведомления |
| Таймеры | `Timer`, `_process`, `_physics_process` |

### Проект 2: Космический шутер (GDScript — средний уровень)
**Язык:** Чистый GDScript  
**Сложность:** ⭐⭐ (Начально-средняя)  
**Результат:** 2D space shooter с врагами, боссами, power-ups

| Тема | Описание |
|------|----------|
| 2D-физика | `CharacterBody2D`, `RigidBody2D`, `Area2D` |
| Коллизии | Слои, маски, группы |
| Object Pool | Паттерн для пуль и частиц |
| Частицы | `GPUParticles2D`, настройка эффектов |
| Шейдеры | Введение в `ShaderMaterial` |
| Враги и AI | Базовые паттерны движения |

### Проект 3: Метроидвания (GDScript — продвинутый)
**Язык:** Чистый GDScript  
**Сложность:** ⭐⭐⭐ (Средняя)  
**Результат:** 2D платформер с исследованием, инвентарём, способностями

| Тема | Описание |
|------|----------|
| TileMap и TileMapLayer | Создание уровней, автотайлинг |
| AnimationTree | Стейт-машина для анимаций |
| State Machine | Паттерн для управления состояниями персонажа |
| Инвентарь | Система предметов и слотов |
| Камеры | `Camera2D`, границы, шейк |
| Способности | Дабл-джамп, дэш, стенолазание |

### Проект 4: Tower Defense (GDScript → C++ переход)
**Язык:** GDScript + C++ (GDExtension)  
**Сложность:** ⭐⭐⭐⭐ (Средне-продвинутая)  
**Результат:** Стратегическая TD-игра с волновой системой

| Тема | Описание |
|------|----------|
| GDExtension | Настройка окружения, первый C++ класс |
| Navigation2D | `NavigationRegion2D`, `NavigationAgent2D` |
| Волновая система | Генерация врагов, усложнение |
| Стратегический AI | Выбор целей, приоритеты |
| Паттерн Strategy | Разные типы башен через интерфейс |
| C++ бенчмарки | pathfinding на GDScript vs C++ |

### Проект 5: 3D Приключение (C++ — основной)
**Язык:** В основном C++ (GDExtension) + GDScript для сцен  
**Сложность:** ⭐⭐⭐⭐⭐ (Продвинутая)  
**Результат:** 3D игра с персонажем, NPC, диалогами, инвентарём

| Тема | Описание |
|------|----------|
| 3D-физика | `CharacterBody3D`, `RigidBody3D` |
| Character Controller | C++ контроллер персонажа |
| NavigationRegion3D | 3D навигация, NavMesh |
| Диалоговая система | C++ движок диалогов |
| Предметы и инвентарь | 3D pickup, инвентарь |
| Освещение и материалы | Environment, свет, пост-процессинг |

### Проект 6: Performance Demo (C++ — продвинутый)
**Язык:** Чистый C++ (GDExtension)  
**Сложность:** ⭐⭐⭐⭐⭐+ (Экспертная)  
**Результат:** Демо с тысячами объектов, мультитрединг, compute shaders

| Тема | Описание |
|------|----------|
| Мультитрединг | `Thread`, mutex, thread-safe очереди |
| Compute Shaders | GPU-вычисления для частиц |
| ECS-подход | Entity Component System на C++ |
| Профилирование | Godot Profiler, кастомные замеры |
| Оптимизация | Batch rendering, LOD, culling |
| Интеграция библиотек | Подключение Box2D, Recast |

## 6. Методология «Анти-Tutorial-Hell»

### 6.1. Три фазы каждого раздела

| Фаза | Что делает ученик | Пример |
|------|-------------------|--------|
| **Понимание** | Читает объяснение + смотрит код инструктора | «Вот как работает State Machine» |
| **Практика** | Выполняет микро-челлендж по аналогии | «Добавь состояние FLEE к NPC» |
| **Применение** | Самостоятельно расширяет проект (спринт) | «Создай 3 типа NPC с разными стейт-машинами» |

### 6.2. Правило 30/70
- 30% времени — теория и объяснения инструктора
- 70% времени — самостоятельная практика и челленджи

### 6.3. Прогрессия сложности челленджей

```
🟢 Базовый: «Измени параметр X, наблюдай результат»
🟡 Продвинутый: «Добавь новую фичу, используя изученный паттерн»  
🔴 Экспертный: «Спроектируй подсистему с нуля по требованиям»
```

### 6.4. «Мосты» между проектами
Явные связи: «В проекте 2 мы использовали Object Pool — в проекте 4 мы вынесем его в C++ и ускорим в 50 раз». Ученик видит непрерывный путь, а не набор разрозненных туториалов.

## 8. Целевая аудитория

### Основной сегмент
- **Возраст:** 18–35 лет
- **Опыт:** Новички в геймдеве, но с базовым пониманием программирования
- **Мотивация:** Хотят создавать игры профессионально, а не как хобби
- **Боль:** Устали от поверхностных туториалов, хотят глубину

### Вторичный сегмент
- Unity/Unreal разработчики, переходящие на Godot
- Программисты (Python, JS), желающие войти в геймдев
- Студенты CS факультетов

### Не целевая аудитория
- Дети до 14 лет (слишком сложно)
- Те, кто хочет «быстрый туториал за 1 час»
- Те, кто не готов писать код

## 9. Формат доставки

Курс доставляется через **интерактивное веб-приложение** (см. `program-concept.md`), а не через видео или PDF. Это даёт:

- Прогресс-трекинг с визуальной картой
- Встроенный редактор кода (Monaco + GDScript Playground)
- Микро-челленджи с проверкой
- Геймификация (XP, бейджи, стрик)
- Godot Web Editor для 2D-проектов (Pro)

Дополнительные форматы:
- **Справочник API** — быстрый доступ к часто используемым методам
- **Cheat Sheets** — одностраничные сводки после каждого проекта
- **Видео-дополнения** — короткие (5-10 мин) пояснения сложных тем (опционально)
