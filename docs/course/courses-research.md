# Введение

Данный документ содержит результаты исследования существующих курсов и учебных материалов по разработке игр на Godot Engine, доступных в открытом доступе на YouTube, образовательных платформах и сайтах-сообществ. Исследование проведено с целью выявления сильных и слабых сторон доступных материалов, определения пробелов в обучении и формулирования рекомендаций для улучшения нашего курса. Мы проанализировали более 30 источников, включая видео-курсы, интерактивные платформы, форумы и отзывы учащихся, чтобы составить полную картину текущего состояния обучения Godot.

# Обзор основных курсов и авторов

## 1. GDQuest (gdquest.com)

GDQuest — наиболее известный и авторитетный создатель обучающих материалов по Godot. Основатель Nathan Lovato — профессиональный геймдизайнер с многолетним опытом. GDQuest предлагает как бесплатные материалы на YouTube, так и платные курсы на собственном сайте. Их флагманский продукт — Learn 2D Gamedev with Godot 4, включающий несколько модулей: основы GDScript, создание 2D-игры в стиле Zelda, продвинутые техники. Также доступен бесплатный интерактивный курс Learn GDScript From Zero — веб-приложение, где можно писать код прямо в браузере.

### Плюсы

- Высокое качество производства видео и визуальных материалов — лучшее среди всех Godot-авторов

- Интерактивный курс Learn GDScript From Zero с упражнениями прямо в браузере — уникальный формат

- Глубокое понимание геймдизайна, а не просто программирования — автор профессиональный геймдизайнер

- Фокус на правильных паттернах и архитектуре с самого начала

- Бесплатный вводный контент позволяет оценить качество перед покупкой

### Минусы

- Платные курсы дорогие (100-200 долларов за модуль) и всё ещё в Early Access

- Крайне медленное обновление — модули выходят годами, а не месяцами

- Нет покрытия C++/GDExtension — исключительно GDScript

- Нет 3D-контента вообще — только 2D

- Структура курса фрагментирована: отдельные модули не образуют единую траекторию

- На Reddit жалобы на отсутствие структуры и ощущение «недоделанности»

## 2. GameDev.tv (gamedev.tv)

GameDev.tv — крупная платформа с курсами по различным игровым движкам. Их Godot-предложение включает несколько курсов: Complete Godot 4 2D, Complete Godot 4 3D, и Action Combat RPG. Курсы доступны как на сайте платформы, так и через Udemy и Humble Bundle. Инструкторы — Bram Williams (3D) и Yann Burrett (2D). Формат — видео-лекции с проектной работой, каждый курс ведёт к созданию конкретной игры.

### Плюсы

- Самый широкий охват тем среди платных курсов: 2D, 3D, RPG — в одном бандле

- Хорошая структура с пошаговым созданием проектов — подходит для начинающих

- Доступен через Humble Bundle по очень низкой цене (15-20 долларов за весь бандл)

- Есть курс по 3D — единственный платный курс с полноценным 3D-покрытием

- Активное сообщество на Discord для помощи учащимся

### Минусы

- Крайне поверхностное покрытие — «царапает поверхность» по отзывам на Reddit

- Чрезмерно ориентирован на новичков: 2 часа видео могут содержать 15 минут полезной информации

- Последний проект в 2D-курсе ведёт другой инструктор — стиль и качество меняются

- Нет покрытия C++/GDExtension

- Качество Godot-курсов заметно ниже, чем Unity-курсов от той же платформы

- Нет продвинутых тем (ECS, многопоточность, оптимизация)

## 3. HeartBeast (YouTube)

HeartBeast (Бенджамин) — один из старейших Godot-авторов на YouTube. Наиболее известен серией Action RPG для Godot 3.2, которую позже переписал для Godot 4. Его стиль — длинные, подробные серии, где он создаёт полноценную игру от начала до конца. Также есть платные курсы на Udemy (Discovering Godot, 1-Bit Godot).

### Плюсы

- Длинные, детальные серии — можно увидеть полный процесс создания игры

- Хорошее покрытие Action RPG-механик: инвентарь, боёвка, враги, уровень

- Бесплатный контент на YouTube полностью функционален — не обрезанная версия платного

- Pixel-art визуал привлекателен и хорошо подходит для обучения

### Минусы

- Архитектура кода часто критикуется — «спагетти-код», глобальные переменные, нет разделения ответственности

- Не обновляется до Godot 4 достаточно долго, многие материалы устарели

- Платные Udemy-курсы на Reddit называют «запутанными и противоречивыми»

- Нет покрытия C++, шейдеров, оптимизации

- Отсутствует систематический подход — обучение через следование, а не понимание

## 4. StayAtHomeDev (YouTube)

StayAtHomeDev — популярный YouTube-автор, создающий туториалы по Godot. Известен еженедельными showcases игр сообщества и организацией Godot Game Awards 2024. Его туториалы охватывают разнообразные темы: от базового управления персонажем до продвинутых механик. Также есть Patreon с эксклюзивным контентом.

### Плюсы

- Активное участие в сообществе Godot — showcases, награды, обратная связь

- Разнообразие тем — от базовых до продвинутых механик

- Регулярный выход нового контента

- Практический подход — каждый туториал решает конкретную задачу

### Минусы

- Нет структурированного курса — отдельные туториалы без связи между собой

- Глубина покрытия ограничена форматом отдельных видео

- Нет C++ или продвинутой оптимизации

- Качество варьируется от видео к видео

## 5. Chevifier (YouTube) — GDExtension Series

Chevifier — автор серии видео по GDExtension для Godot 4, включающей настройку окружения, SCons, основы C++ и интеграцию с Godot. Это одна из немногих серий, полностью посвящённых C++ в Godot. Серия состоит из нескольких частей и покрывает базовые аспекты GDExtension.

### Плюсы

- Практически единственная бесплатная серия по GDExtension на YouTube

- Пошаговая настройка окружения сборки — самое сложное для новичков в C++

- Включает краткий курс C++ для тех, кто знает только GDScript

### Минусы

- Очень короткая серия — лишь базовые аспекты, нет реальных проектов

- Нет покрытия продвинутых техник (ECS, многопоточность, compute-шейдеры)

- Нет бенчмарков или сравнений производительности GDScript vs C++

- Качество производства ниже, чем у GDQuest или GameDev.tv

## 6. Русскоязычные ресурсы

### Stepik: «Godot для абсолютных новичков»

Бесплатный курс на Stepik, ориентированный на создание 2D-платформера. Включает основы GDScript, работу со спрайтами, физику и интерфейс. Курс на русском языке — одно из немногих структурированных предложений на русском.

- Плюсы: на русском языке, структурированный, бесплатный, интерактивный

- Минусы: очень базовый, только один проект, устаревший Godot 3.x, нет C++ и 3D

### itProger: «Godot Engine для начинающих»

Видео-курс на русском языке, покрывающий основы Godot и GDScript. Формат — набор видеоуроков с практическими примерами.

- Плюсы: на русском, бесплатно, подходит для первого знакомства

- Минусы: поверхностный, нет углублённых тем, нет C++ и 3D, качество ниже международных аналогов

### Айтигенио / PIXEL / Coddyschool

Платные курсы для детей, ориентированные на базовое знакомство с Godot и GDScript. Формат — живые занятия с преподавателем.

- Плюсы: живое общение с преподавателем, адаптация для детей

- Минусы: дорого, крайне поверхностно, нет продвинутых тем, маркетинговый характер

## 7. Godot Tutorials (godottutorials.com)

Сайт godottutorials.com — один из старейших текстовых ресурсов по Godot. Автор создаёт подробные письменные туториалы, покрывающие широкий спектр тем от основ до продвинутых техник. Заявленная цель — «создать видео высочайшего качества, чтобы вывести вас на следующий уровень, бесплатно».

### Плюсы

- Текстовый формат — удобнее для справки и повторного чтения, чем видео

- Бесплатный и полный контент без обрезания

- Широкий спектр тем

### Минусы

- Обновления нерегулярны и медленны

- Нет структурированного курса — отдельные статьи

- Нет C++/GDExtension покрытия

- Визуальное качество ниже, чем у видео-конкурентов

## 8. Официальная документация Godot

Официальная документация Godot (docs.godotengine.org) включает tutorial раздел, справочник по классам и раздел GDExtension. Также доступен интерактивный Learn GDScript From Zero, размещённый на сайте документации. Документация — это не курс, а справочный материал, но она является обязательным ресурсом для любого разработчика на Godot.

### Плюсы

- Самый точный и актуальный источник — поддерживается командой Godot

- Бесплатный и всегда доступный

- Единственный надёжный источник по GDExtension API

- Доступен на русском языке (частичный перевод)

### Минусы

- Не является курсом — нет учебной траектории, нет проектов

- Сухой, энциклопедический стиль — не подходит для начинающих

- Примеры минимальны и не показывают реальных сценариев использования

- Раздел GDExtension — больше справочник, чем учебник

# Ключевые проблемы существующих курсов

## 1. Проблема Tutorial Hell

Самая распространённая жалоба в сообществе Godot — «tutorial hell» (аду туториалов). Это состояние, когда учащийся может повторить туториал шаг за шагом, но не способен создать собственную игру. Причина: большинство курсов учат следовать инструкциям, а не понимать принципы. Учащийся копирует код, но не понимает, почему он написан именно так. Когда нужно создать что-то своё — он теряется. Наш курс должен активно бороться с этим: после каждого раздела давать задания на модификацию, а не повторение; объяснять «почему», а не только «как»; создавать условия, где нужно применять знания самостоятельно.

## 2. Отсутствие траектории GDScript → C++

Ни один существующий курс не предлагает плавного перехода от GDScript к C++. Это огромный пробел: GDQuest фокусируется только на GDScript, Chevifier даёт лишь базовую настройку C++, а GameDev.tv вообще не затрагивает тему. Между тем, для серьёзной разработки игр на Godot знание C++/GDExtension становится всё более важным — только через C++ можно достичь максимальной производительности, интегрировать сторонние библиотеки и расширять движок. Наш курс — единственный, который предлагает осмысленную траекторию от GDScript к C++, где каждый шаг перехода мотивирован реальной потребностью в производительности.

## 3. Поверхностное покрытие архитектуры

Большинство курсов учат писать код, но не учат проектировать системы. HeartBeast критикуют за спагетти-код, GameDev.tv даёт лишь базовые паттерны, GDQuest лучше других, но и он не покрывает архитектуру сложных проектов. В реальной разработке умение спроектировать систему (конечный автомат, пул объектов, менеджер состояний) важнее, чем знание конкретных API. Наш курс должен вводить паттерны проектирования не как абстрактную теорию, а как решения реальных проблем, возникающих при создании конкретных проектов.

## 4. Нет обучения оптимизации и профилированию

Ни один курс не учит, как измерять и улучшать производительность. Это критический пробел: когда проект вырастает, производительность становится главным ограничением. Разработчик, не умеющий профилировать, будет оптимизировать не те места или переписывать код на C++ без необходимости. Наш курс должен включать: практику работы с Godot Profiler, бенчмарки GDScript vs C++, понимание узких мест CPU vs GPU, осознанный подход к оптимизации (измерять → оптимизировать → измерять).

## 5. Разрыв между 2D и 3D

GameDev.tv — единственный платный курс с 3D-покрытием, и его качество значительно ниже 2D-части. Бесплатные ресурсы почти исключительно 2D. При этом переход от 2D к 3D в Godot — это не просто добавление третьей оси: это другие узлы (CharacterBody3D vs CharacterBody2D), другая система камеры, другая навигация, другой подход к освещению. Наш курс обеспечивает плавный переход, начиная 3D в проекте 5 с полным объяснением различий.

# Полезные приёмы из существующих курсов

## Из GDQuest

- Интерактивные упражнения в браузере — идеальны для закрепления основ. Мы можем добавить QR-коды или ссылки на веб-упражнения в каждый раздел.

- Фокус на «почему», а не только «как» — каждый концепт объясняется через проблему, которую он решает. Это критически важно для преодоления tutorial hell.

- Визуальное качество производства — эталон для индустрии. Демонстрации должны быть чёткими, с выделением ключевых элементов.

- Система прогрессии: каждый модуль строится на предыдущем. Мы используем этот подход, но усиливаем его явными ссылками между проектами.

## Из GameDev.tv

- Структура «один курс → одна игра» — эффективна для мотивации учащихся. Мы используем тот же подход с 6 проектами.

- Humble Bundle как канал дистрибуции — доступность по низкой цене привлекает широкую аудиторию.

- Активное сообщество Discord — критически важно для помощи при застревании. Рекомендуем создать канал поддержки для нашего курса.

- Разделение на секции с контрольными точками (checkpoint) — даёт ощущение прогресса.

## Из HeartBeast

- Длинные серии полного создания игры — показывают реальный процесс, включая ошибки и исправления. Это делает обучение более реалистичным.

- Pixel-art визуал — привлекателен и минимизирует затраты на ассеты. Мы можем рекомендовать бесплатные наборы пиксель-арт ассетов.

- Ориентация на конкретный жанр (Action RPG) — глубже, чем поверхностный обзор нескольких жанров.

## Из Chevifier

- Пошаговая настройка C++-окружения — самое ценное в серии. Мы должны включить детальную инструкцию по настройке, включая типичные ошибки.

- Встроенный мини-курс C++ для GDScript-разработчиков — отличный мост между языками. Наш курс расширяет этот подход.

## Из русскоязычных ресурсов

- Stepik-формат с автоматической проверкой заданий — мощный инструмент обучения. Можно создать дополнительный курс на Stepik как компаньон к нашему.

- Русский язык — огромное конкурентное преимущество для русскоязычной аудитории, которая плохо владеет английским.

## Дополнительные рекомендации

- Добавить раздел «Частые ошибки» в каждый проект — это самый запрашиваемый контент на форумах помощи

- Включить сравнительные таблицы Godot vs Unity/Unreal для аудитории с опытом в других движках

- Создать шпаргалки (cheat sheets) по GDScript и C++ API Godot для быстрого справочника

- Рассмотреть возможность создания companion-репозитория на GitHub с готовым кодом всех проектов

# Уникальные преимущества нашего курса

Подводя итог исследованию, наш курс обладает следующими уникальными преимуществами, которых нет ни у одного из существующих предложений:

| На русском языке | Полный курс на русском с технической точностью | Только детские/базовые курсы |

Наш курс заполняет несколько критических пробелов одновременно: переход от GDScript к C++, обучение оптимизации и профилированию, покрытие 3D, продвинутые C++-техники (ECS, многопоточность) — и всё это на русском языке. Ни один существующий ресурс не закрывает хотя бы два из этих пробелов одновременно, что делает наш курс уникальным и высоко востребованным.
