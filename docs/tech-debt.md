## Рекомендации по устранению

### Критический приоритет

- **TD-001 · CI/CD** — ⏸️ Отложено. На первых порах тестирование проводится вручную на локальной машине. Будет настроен перед публичным релизом: GitHub Actions для линтинга, сборки и деплоя.
- **TD-002 · Тесты** — Подключить Vitest + React Testing Library. Покрыть минимум критические пути: рендеринг уроков, API-маршруты, бизнес-логика прогресса.

### Высокий приоритет

- **TD-003 · Мониторинг** — Интегрировать Sentry для отслеживания ошибок и Axiom для логирования. Настроить source maps.
- **TD-004 · Аутентификация** — ⏸️ Отложено. NextAuth.js с провайдерами GitHub/Google будет добавлен перед публичным релизом. На этапе разработки все функции доступны без авторизации.
- **TD-030 · Prisma версия** — Унифицировать версию Prisma между песочницей и git-репо. Либо обновить песочницу до v7, либо даунгрейднуть git-репо до v6. Рекомендуется обновить песочницу.
- **TD-032 · XP-неконсистентность** — Исправить `progress.repository.ts`: убрать `XP_PER_CHAPTER = 50` и использовать XP из `_meta.json`, передаваемый через Server Action.

### Средний приоритет

- **TD-006 · Docker** — Создать Dockerfile и docker-compose.yml для production-деплоя. Продумать переменные окружения и тома для Prisma.
- **TD-007 · Godot Web Editor** — Развернуть self-hosted Godot Web Editor. Настроить проброс файлов проектов через API.
- **TD-008 · GDScript Playground** — Исследовать возможность интеграции GDScript WASM runtime для интерактивных примеров кода.
- **TD-016 · JSON-челленджи** — Конвертировать микровызовы из Markdown в структурированный JSON (id, описание, starter_code, test_cases, hints, xp) для интеграции с платформой. Ориентировочно 113 челленджей.
- **TD-017 · Starter-шаблоны** — Создать минимальные Godot-проекты для каждого из 6 проектов курса. Размеры от 50 KB (P1) до 2 MB (P6).
- **TD-031 · Sidebar захардкожен** — Переписать Sidebar на динамическую загрузку глав из `_meta.json` через `getProjectChapters()`. Убрать дублирование данных.

### Низкий приоритет

- **TD-018 · Видеодополнения** — Короткие (5–10 мин) видео для сложных тем: ECS на практике (P6), настройка GDExtension (P4), State Machine в AnimationTree (P3), бенчмарки GDScript vs C++ (P4), compute-шейдеры (P6).
