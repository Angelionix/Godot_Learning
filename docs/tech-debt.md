## Рекомендации по устранению

### Критический приоритет

- **TD-001 · CI/CD** — ⏸️ Отложено. На первых порах тестирование проводится вручную на локальной машине. Будет настроен перед публичным релизом: GitHub Actions для линтинга, сборки и деплоя.

### Высокий приоритет

- **TD-004 · Аутентификация** — ⏸️ Отложено. NextAuth.js с провайдерами GitHub/Google будет добавлен перед публичным релизом. Создан `src/lib/auth.ts` с `getUserId()` — единая точка подмены при внедрении auth.

### Низкий приоритет

- **TD-018 · Видеодополнения** — Короткие (5–10 мин) видео для сложных тем: ECS на практике (P6), настройка GDExtension (P4), State Machine в AnimationTree (P3), бенчмарки GDScript vs C++ (P4), compute-шейдеры (P6). Требует отдельной продакшн-инфраструктуры.

### Выполнено в этом спринте (v0.12.0)

- **TD-003 · Мониторинг** — ✅ Выполнено. Интегрирован `@sentry/nextjs` SDK: `sentry.client.config.ts`, `sentry.server.config.ts`, `sentry.edge.config.ts`. `next.config.ts` обёрнут в `withSentryConfig`. Активируется только при `SENTRY_DSN` env variable + production mode. Настроены source maps, tunnel route `/monitoring`, Replay integration.
- **TD-030 · Prisma версия** — ✅ Выполнено. Обе зависимости (`prisma` и `@prisma/client`) используют `^6.11.1`, разрешаются в v6.19.2. Несовместимости нет.
- **TD-031 · Sidebar захардкожен** — ✅ Выполнено. Sidebar переписан: данные глав передаются как props из server-side layout (чтение `_meta.json` через `getAllProjects()`). `chapter-data.ts` помечен как `@deprecated`. Удалено дублирование данных.
- **TD-035 · GDScript интерпретатор** — ✅ Выполнено. Добавлены Godot API stubs: `get_node()`, `$NodePath`, `%UniqueNode`, `get_tree()`, `get_parent()`, `queue_free()`, `add_child()`, `remove_child()`, `move_and_slide()`, `move_and_collide()`, `is_instance_valid()`, `is_zero_approx()`, `wrap()`, `snapped()`. Добавлены типы: `Vector2i`, `Vector3`, `Vector3i`, `Rect2`, `Dictionary`, `Resource`, `Node`. Mock-дерево сцен: `__mockTree.create_timer()`, `change_scene_to_file()`, и т.д. Улучшена обработка `await` (timer vs signal).
- **TD-036 · Challenge DB** — ✅ Выполнено. `InteractiveChallenge` переведён с REST API (`fetch('/api/challenges')`) на Server Action (`challengeAttemptAction`). Устранён network round-trip, улучшена типизация.
- **TD-037 · Monaco skeleton** — ✅ Выполнено. Добавлен полноценный skeleton-placeholder для Monaco Editor: анимированные блоки заголовка, редактора, кнопок. Отображается при первой загрузке (~3MB).
