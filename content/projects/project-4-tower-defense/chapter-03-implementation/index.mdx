## 3.1 Data Layer — ресурсы данных

Data Layer содержит ресурсы, описывающие игровые объекты без какой-либо логики. Все ресурсы наследуют Resource и используют @export для настройки в инспекторе редактора. Это позволяет гейм-дизайнеру менять баланс, не трогая код, а программисту — ссылаться на типизированные данные вместо магических чисел. Каждый ресурс предоставляет вычисляемые свойства (например, get_dps()), которые инкапсулируют формулы.

### resources/tower_data.gd

Ресурс TowerData описывает все параметры одного типа башни. Конкретные башни (Gun, Splash, Slow, Laser) отличаются только значениями в этом ресурсе, а не кодом. Методы get_dps(), get_upgrade_cost(), get_damage_at_level() и get_range_at_level() инкапсулируют формулы баланса, чтобы код башни не содержал вычислений.

```gdscript
class_name TowerData
extends Resource

@export var tower_name: String = "Gun Tower"
@export var tower_scene: PackedScene
@export var projectile_scene: PackedScene
@export var cost: int = 100
@export var damage: float = 15.0
@export var attack_speed: float = 1.0  # атак в секунду
@export var attack_range: float = 150.0
@export var target_strategy: StringName = &"first"
@export var splash_radius: float = 0.0  # 0 = одиночная цель
@export var slow_factor: float = 1.0  # 1.0 = без замедления, 0.5 = 50% замедление
@export var slow_duration: float = 0.0  # секунды действия замедления
@export var projectile_speed: float = 300.0
@export var upgrade_cost_multiplier: float = 0.6
@export var upgrade_damage_multiplier: float = 1.5
@export var upgrade_range_bonus: float = 15.0
@export var icon: Texture2D
@export var description: String = ""


func get_dps() -> float:
        return damage * attack_speed


func get_upgrade_cost(current_level: int) -> int:
        if current_level <= 0:
                return cost
        var multiplier := upgrade_cost_multiplier
        for i in range(current_level):
                multiplier *= 1.3
        return int(cost * multiplier)


func get_damage_at_level(level: int) -> float:
        return damage * pow(upgrade_damage_multiplier, level)


func get_range_at_level(level: int) -> float:
        return attack_range + upgrade_range_bonus * level
```

### resources/enemy_data.gd

Ресурс EnemyData описывает все параметры одного типа врага. Метод get_health_per_gold() используется для анализа баланса: чем выше HP за золото, тем «дороже» враг для игрока. slow_resistance определяет, насколько враг устойчив к замедлению: 0 = полностью подвержен, 1 = полностью иммунен.

```gdscript
class_name EnemyData
extends Resource

@export var enemy_name: String = "Basic Enemy"
@export var enemy_scene: PackedScene
@export var max_health: float = 50.0
@export var move_speed: float = 80.0
@export var gold_reward: int = 15
@export var lives_cost: int = 1  # сколько жизней теряет игрок при достижении базы
@export var is_boss: bool = false
@export var slow_resistance: float = 0.0  # 0 = полностью подвержен, 1 = иммунен
@export var sprite_color: Color = Color.RED
@export var scale: float = 1.0


func get_health_per_gold() -> float:
        if gold_reward <= 0:
                return 0.0
        return max_health / float(gold_reward)
```

### resources/wave_data.gd

Ресурс WaveData описывает одну волну врагов. Массив spawn_groups определяет, какие враги и в каком количестве появляются. Методы get_total_enemies() и get_total_gold() используются WaveManager для отображения информации о волне и расчёта дохода.

```gdscript
class_name WaveData
extends Resource

@export var wave_number: int = 1
@export var spawn_groups: Array[SpawnGroup] = []
@export var start_delay: float = 5.0
@export var speed_bonus: int = 20


func get_total_enemies() -> int:
        var total := 0
        for group in spawn_groups:
                total += group.count
        return total


func get_total_gold() -> int:
        var total := 0
        for group in spawn_groups:
                if group.enemy_data:
                        total += group.enemy_data.gold_reward * group.count
        return total
```

### resources/spawn_group.gd

Ресурс SpawnGroup описывает одну группу врагов внутри волны. interval задаёт секунды между спавнами, а delay_after — паузу после последнего врага группы перед следующей группой.

```gdscript
class_name SpawnGroup
extends Resource

@export var enemy_data: EnemyData
@export var count: int = 5
@export var interval: float = 1.0  # секунд между спавнами
@export var delay_after: float = 2.0  # пауза после последнего врага группы
```

## 3.2 Logic Layer — глобальные менеджеры

Logic Layer содержит глобальные менеджеры, реализованные как Autoload. Каждый менеджер отвечает за свою подсистему и общается с другими через сигналы. Это обеспечивает слабую связанность: например, EconomyManager не знает о HUD, но HUD подписан на сигнал balance_changed и обновляет отображение при изменении баланса.

### scripts/game_manager.gd (Autoload)

GameManager управляет глобальным состоянием игры: жизни, пауза, поражение. Сигналы lives_changed и game_over используются другими системами для реагирования на изменения. Метод toggle_pause() переключает паузу через get_tree().paused, а process_mode = PROCESS_MODE_ALWAYS позволяет менеджеру работать даже в паузе.

```gdscript
extends Node

signal lives_changed(new_lives: int)
signal game_over()
signal game_paused(is_paused: bool)

var lives: int = 20
var is_paused: bool = false
var current_wave: int = 0
var is_game_over: bool = false


func _ready() -> void:
        process_mode = Node.PROCESS_MODE_ALWAYS


func lose_life(amount: int = 1) -> void:
        if is_game_over:
                return
        lives = maxi(lives - amount, 0)
        lives_changed.emit(lives)
        if lives <= 0:
                _on_game_over()


func _on_game_over() -> void:
        is_game_over = true
        game_over.emit()
        get_tree().paused = true


func toggle_pause() -> void:
        is_paused = !is_paused
        get_tree().paused = is_paused
        game_paused.emit(is_paused)


func reset_game() -> void:
        lives = 20
        current_wave = 0
        is_game_over = false
        is_paused = false
        get_tree().paused = false


func get_save_data() -> Dictionary:
        return {
                "lives": lives,
                "current_wave": current_wave,
                "is_game_over": is_game_over,
        }


func load_save_data(data: Dictionary) -> void:
        lives = data.get("lives", 20)
        current_wave = data.get("current_wave", 0)
        is_game_over = data.get("is_game_over", false)
        lives_changed.emit(lives)
```

### scripts/wave_manager.gd (Autoload)

WaveManager реализован как конечный автомат с тремя состояниями: Idle (ожидание между волнами), Spawning (спавн врагов текущей волны) и Active (все враги заспавнены, ожидание уничтожения). Переходы управляются таймерами и событиями. Метод request_skip() позволяет игроку досрочно запустить следующую волну за бонусное золото.

```gdscript
extends Node

signal wave_started(wave_number: int)
signal wave_completed(wave_number: int)
signal all_waves_completed()

enum State { IDLE, SPAWNING, ACTIVE }

var current_state: State = State.IDLE
var current_wave: int = 0
var max_waves: int = 15
var idle_timer: float = 0.0
var skip_requested: bool = false
var spawn_queue: Array[Dictionary] = []
var spawn_timer: float = 0.0
var wave_data_array: Array[WaveData] = []


func _ready() -> void:
        _load_wave_data()


func _load_wave_data() -> void:
        wave_data_array.clear()
        for i in range(1, max_waves + 1):
                var path := "res://resources/wave_%02d_data.tres" % i
                if ResourceLoader.exists(path):
                        var data := load(path) as WaveData
                        if data:
                                wave_data_array.append(data)


func _physics_process(delta: float) -> void:
        match current_state:
                State.IDLE:
                        idle_timer -= delta
                        if idle_timer <= 0.0 or skip_requested:
                                skip_requested = false
                                _start_wave()
                State.SPAWNING:
                        _process_spawn_queue(delta)
                State.ACTIVE:
                        if get_tree().get_nodes_in_group("enemies").is_empty():
                                _wave_completed()


func request_skip() -> void:
        if current_state == State.IDLE:
                skip_requested = true


func _start_wave() -> void:
        current_wave += 1
        if current_wave > max_waves:
                all_waves_completed.emit()
                current_state = State.IDLE
                return

        if current_wave > wave_data_array.size():
                current_state = State.IDLE
                return

        var wave: WaveData = wave_data_array[current_wave - 1]
        wave_started.emit(current_wave)
        GameManager.current_wave = current_wave

        _build_spawn_queue(wave)
        current_state = State.SPAWNING


func _build_spawn_queue(wave: WaveData) -> void:
        spawn_queue.clear()
        for group in wave.spawn_groups:
                for i in range(group.count):
                        spawn_queue.append({
                                "enemy_data": group.enemy_data,
                                "interval": group.interval,
                                "delay_after": group.delay_after if i == group.count - 1 else 0.0,
                        })
        spawn_timer = wave.start_delay


func _process_spawn_queue(delta: float) -> void:
        if spawn_queue.is_empty():
                current_state = State.ACTIVE
                return

        spawn_timer -= delta
        if spawn_timer <= 0.0:
                var entry: Dictionary = spawn_queue.pop_front()
                var data: EnemyData = entry["enemy_data"]
                _spawn_enemy(data)
                spawn_timer = entry["interval"]
                if entry["delay_after"] > 0.0:
                        spawn_timer += entry["delay_after"]


func _spawn_enemy(data: EnemyData) -> void:
        if not data or not data.enemy_scene:
                return
        var enemy: CharacterBody2D = data.enemy_scene.instantiate()
        var spawn_point: Marker2D = get_tree().get_first_node_in_group("spawn_point") as Marker2D
        var base_point: Marker2D = get_tree().get_first_node_in_group("base_point") as Marker2D

        if spawn_point:
                enemy.global_position = spawn_point.global_position
        if base_point and enemy.has_node("NavigationAgent2D"):
                var nav: NavigationAgent2D = enemy.get_node("NavigationAgent2D")
                nav.target_position = base_point.global_position

        enemy.add_to_group("enemies")
        var enemies_container := get_tree().get_first_node_in_group("enemies_container")
        if enemies_container:
                enemies_container.add_child(enemy)
        else:
                get_tree().current_scene.add_child(enemy)


func _wave_completed() -> void:
        wave_completed.emit(current_wave)
        EconomyManager.earn(wave_data_array[current_wave - 1].speed_bonus)
        current_state = State.IDLE
        idle_timer = 10.0  # секунд между волнами


func get_save_data() -> Dictionary:
        return {
                "current_wave": current_wave,
                "current_state": current_state,
        }


func load_save_data(data: Dictionary) -> void:
        current_wave = data.get("current_wave", 0)
        current_state = State.IDLE
```

### scripts/economy_manager.gd (Autoload)

EconomyManager управляет балансом золота, расходами на башни и доходами от убийств. Метод spend() проверяет возможность оплаты и испускает сигнал balance_changed при изменении. Метод get_sell_value() вычисляет стоимость продажи с учётом коэффициента 0.7.

```gdscript
extends Node

signal balance_changed(new_balance: int)

var balance: int = 200
var sell_ratio: float = 0.7
var total_earned: int = 0
var total_spent: int = 0


func can_afford(cost: int) -> bool:
        return balance >= cost


func spend(amount: int) -> bool:
        if not can_afford(amount):
                return false
        balance -= amount
        total_spent += amount
        balance_changed.emit(balance)
        return true


func earn(amount: int) -> void:
        balance += amount
        total_earned += amount
        balance_changed.emit(balance)


func get_sell_value(total_invested: int) -> int:
        return int(total_invested * sell_ratio)


func reset() -> void:
        balance = 200
        total_earned = 0
        total_spent = 0
        balance_changed.emit(balance)


func get_save_data() -> Dictionary:
        return {
                "balance": balance,
                "total_earned": total_earned,
                "total_spent": total_spent,
        }


func load_save_data(data: Dictionary) -> void:
        balance = data.get("balance", 200)
        total_earned = data.get("total_earned", 0)
        total_spent = data.get("total_spent", 0)
        balance_changed.emit(balance)
```

### scripts/path_manager.gd (Autoload)

PathManager управляет навигационной областью и точками маршрута. Метод setup() вызывается один раз при инициализации карты. Метод request_path_update() перезапекает навигационный полигон при изменении карты (установка/продажа башни в будущем микровызове).

```gdscript
extends Node

var waypoints: Array[Vector2] = []
var navigation_region: NavigationRegion2D = null


func setup(region: NavigationRegion2D, points: Array[Vector2]) -> void:
        navigation_region = region
        waypoints = points


func get_spawn_position() -> Vector2:
        if waypoints.is_empty():
                return Vector2.ZERO
        return waypoints[0]


func get_base_position() -> Vector2:
        if waypoints.is_empty():
                return Vector2.ZERO
        return waypoints[waypoints.size() - 1]


func request_path_update() -> void:
        if navigation_region:
                navigation_region.bake_navigation_polygon()
```

### scripts/tower_registry.gd (Autoload)

TowerRegistry реализует паттерн Factory: хранит словарь TowerData по ключу (StringName) и предоставляет доступ к определениям башен. Магазин башен (TowerShop) использует get_all_tower_keys() для построения списка кнопок, а placement-логика использует get_tower_data() для получения сцены и параметров.

```gdscript
extends Node

var tower_data_map: Dictionary = {}  # StringName -> TowerData


func _ready() -> void:
        _register_towers()


func _register_towers() -> void:
        _load_tower_data(&"gun", "res://resources/tower_gun_data.tres")
        _load_tower_data(&"splash", "res://resources/tower_splash_data.tres")
        _load_tower_data(&"slow", "res://resources/tower_slow_data.tres")
        _load_tower_data(&"laser", "res://resources/tower_laser_data.tres")


func _load_tower_data(key: StringName, path: String) -> void:
        if ResourceLoader.exists(path):
                var data := load(path) as TowerData
                if data:
                        tower_data_map[key] = data


func get_tower_data(key: StringName) -> TowerData:
        return tower_data_map.get(key) as TowerData


func get_all_tower_keys() -> Array[StringName]:
        var keys: Array[StringName] = []
        for key in tower_data_map:
                keys.append(key)
        return keys
```

### scripts/audio_manager.gd (Autoload)

AudioManager управляет звуковыми эффектами и фоновой музыкой. Использует пул из 8 AudioStreamPlayer для одновременного воспроизведения нескольких SFX. Если все каналы заняты, первый канал прерывается для воспроизведения нового звука. BGM воспроизводится через отдельный AudioStreamPlayer.

```gdscript
extends Node

var sfx_players: Array[AudioStreamPlayer] = []
var bgm_player: AudioStreamPlayer = null
var max_sfx_channels: int = 8


func _ready() -> void:
        for i in range(max_sfx_channels):
                var player := AudioStreamPlayer.new()
                add_child(player)
                sfx_players.append(player)
        bgm_player = AudioStreamPlayer.new()
        add_child(bgm_player)


func play_sfx(stream: AudioStream, volume_db: float = 0.0) -> void:
        for player in sfx_players:
                if not player.playing:
                        player.stream = stream
                        player.volume_db = volume_db
                        player.play()
                        return
        # Все каналы заняты, прерываем первый
        sfx_players[0].stream = stream
        sfx_players[0].volume_db = volume_db
        sfx_players[0].play()


func play_bgm(stream: AudioStream) -> void:
        if bgm_player.stream == stream and bgm_player.playing:
                return
        bgm_player.stream = stream
        bgm_player.play()


func stop_bgm() -> void:
        bgm_player.stop()
```

## 3.3 Presentation Layer — сцены и компоненты

Presentation Layer содержит визуальные компоненты, которые отображают данные из Data Layer и реагируют на сигналы из Logic Layer. Важно, что эти компоненты не содержат бизнес-логики: башня не решает, может ли игрок позволить себе покупку — это делает EconomyManager. Башня только получает данные и визуализирует атаку.

### scripts/tower.gd

Скрипт башни — один из самых сложных в проекте. Он управляет обнаружением врагов через Area2D, выбором цели по стратегии, атакой с созданием снарядов и визуализацией дальности. Ключевой момент: башня не создаёт снаряды напрямую в контейнере через хрупкую ссылку `get_parent().get_node("Projectiles")`, а использует группу "projectiles_container" для поиска контейнера.

```gdscript
extends Node2D

@export var tower_data: TowerData
@export var level: int = 0

var enemies_in_range: Array[CharacterBody2D] = []
var current_target: CharacterBody2D = null
var attack_timer: float = 0.0
var show_range: bool = false
var total_invested: int = 0

@onready var muzzle: Marker2D = %Muzzle
@onready var range_area: Area2D = %RangeArea
@onready var attack_cooldown: Timer = %AttackCooldown
@onready var turret_pivot: Node2D = %TurretPivot


func _ready() -> void:
        if tower_data:
                total_invested = tower_data.cost
                _setup_range()
        range_area.body_entered.connect(_on_range_entered)
        range_area.body_exited.connect(_on_range_exited)


func _setup_range() -> void:
        var shape := range_area.get_node("CollisionShape2D").shape as CircleShape2D
        if shape:
                shape.radius = tower_data.get_range_at_level(level)


func _physics_process(delta: float) -> void:
        if not tower_data:
                return
        attack_timer -= delta
        _find_target()
        if current_target:
                _rotate_turret_toward(current_target.global_position)
                if attack_timer <= 0.0:
                        _attack()
                        attack_timer = 1.0 / tower_data.attack_speed


func _on_range_entered(body: Node2D) -> void:
        if body.is_in_group("enemies") and body is CharacterBody2D:
                if not enemies_in_range.has(body):
                        enemies_in_range.append(body)


func _on_range_exited(body: Node2D) -> void:
        if body in enemies_in_range:
                enemies_in_range.erase(body)
                if body == current_target:
                        current_target = null


func _find_target() -> void:
        _clean_dead_enemies()
        if enemies_in_range.is_empty():
                current_target = null
                return
        match tower_data.target_strategy:
                &"first":
                        current_target = _target_first()
                &"last":
                        current_target = _target_last()
                &"strongest":
                        current_target = _target_strongest()
                _:
                        current_target = _target_first()


func _clean_dead_enemies() -> void:
        var to_remove: Array[CharacterBody2D] = []
        for e in enemies_in_range:
                if not is_instance_valid(e) or e.is_queued_for_deletion():
                        to_remove.append(e)
        for e in to_remove:
                enemies_in_range.erase(e)


func _target_first() -> CharacterBody2D:
        var best: CharacterBody2D = null
        var best_progress: float = -1.0
        for e in enemies_in_range:
                if e.has_method("get_path_progress") and e.get_path_progress() > best_progress:
                        best_progress = e.get_path_progress()
                        best = e
        return best


func _target_last() -> CharacterBody2D:
        var best: CharacterBody2D = null
        var best_progress: float = INF
        for e in enemies_in_range:
                if e.has_method("get_path_progress") and e.get_path_progress() < best_progress:
                        best_progress = e.get_path_progress()
                        best = e
        return best


func _target_strongest() -> CharacterBody2D:
        var best: CharacterBody2D = null
        var best_hp: float = -1.0
        for e in enemies_in_range:
                if e.has_method("get_current_health") and e.get_current_health() > best_hp:
                        best_hp = e.get_current_health()
                        best = e
        return best


func _rotate_turret_toward(target_pos: Vector2) -> void:
        if turret_pivot:
                turret_pivot.look_at(target_pos)


func _attack() -> void:
        if not current_target or not tower_data or not tower_data.projectile_scene:
                return
        var proj: Area2D = tower_data.projectile_scene.instantiate()
        proj.global_position = muzzle.global_position
        var projectiles_container := get_tree().get_first_node_in_group("projectiles_container")
        if projectiles_container:
                projectiles_container.add_child(proj)
        else:
                get_parent().add_child(proj)
        if proj.has_method("initialize"):
                proj.initialize(
                        current_target,
                        tower_data.get_damage_at_level(level),
                        tower_data.splash_radius,
                        tower_data.slow_factor,
                        tower_data.slow_duration,
                        tower_data.projectile_speed
                )


func _draw() -> void:
        if show_range and tower_data:
                var range := tower_data.get_range_at_level(level)
                draw_circle(Vector2.ZERO, range, Color(1.0, 1.0, 1.0, 0.1))
                draw_arc(Vector2.ZERO, range, 0.0, TAU, 64, Color(1.0, 1.0, 1.0, 0.3), 1.0)


func set_show_range(value: bool) -> void:
        show_range = value
        queue_redraw()


func upgrade() -> bool:
        var upgrade_cost := tower_data.get_upgrade_cost(level + 1)
        if not EconomyManager.can_afford(upgrade_cost):
                return false
        if not EconomyManager.spend(upgrade_cost):
                return false
        level += 1
        total_invested += upgrade_cost
        _setup_range()
        queue_redraw()
        return true


func sell() -> void:
        var sell_value := EconomyManager.get_sell_value(total_invested)
        EconomyManager.earn(sell_value)
        queue_free()
```

### scripts/tower_laser.gd

Лазерная башня использует непрерывный урон вместо снарядов. Она рисует луч (Line2D) от дула к цели и наносит урон каждый кадр, умноженный на delta. Это обеспечивает плавный DPS: если tower_data.damage = 40, то при 60 FPS башня наносит 40/60 ≈ 0.67 урона за кадр, что даёт 40 DPS.

```gdscript
extends Node2D

@export var tower_data: TowerData
@export var level: int = 0

var enemies_in_range: Array[CharacterBody2D] = []
var current_target: CharacterBody2D = null
var show_range: bool = false
var total_invested: int = 0
var is_firing: bool = false

@onready var muzzle: Marker2D = %Muzzle
@onready var range_area: Area2D = %RangeArea
@onready var turret_pivot: Node2D = %TurretPivot
@onready var line_2d: Line2D = $Line2D


func _ready() -> void:
        if tower_data:
                total_invested = tower_data.cost
                _setup_range()
        range_area.body_entered.connect(_on_range_entered)
        range_area.body_exited.connect(_on_range_exited)
        if line_2d:
                line_2d.visible = false


func _setup_range() -> void:
        var shape := range_area.get_node("CollisionShape2D").shape as CircleShape2D
        if shape:
                shape.radius = tower_data.get_range_at_level(level)


func _physics_process(delta: float) -> void:
        if not tower_data:
                return
        _find_target()
        if current_target and is_instance_valid(current_target):
                _rotate_turret_toward(current_target.global_position)
                _fire_laser(delta)
        else:
                _stop_laser()


func _fire_laser(delta: float) -> void:
        is_firing = true
        if line_2d:
                line_2d.visible = true
                line_2d.clear_points()
                line_2d.add_point(muzzle.global_position - global_position)
                line_2d.add_point(current_target.global_position - global_position)
        if current_target.has_method("take_damage"):
                current_target.take_damage(tower_data.get_damage_at_level(level) * delta)


func _stop_laser() -> void:
        is_firing = false
        if line_2d:
                line_2d.visible = false


func _on_range_entered(body: Node2D) -> void:
        if body.is_in_group("enemies") and body is CharacterBody2D:
                if not enemies_in_range.has(body):
                        enemies_in_range.append(body)


func _on_range_exited(body: Node2D) -> void:
        if body in enemies_in_range:
                enemies_in_range.erase(body)
                if body == current_target:
                        current_target = null


func _find_target() -> void:
        # Очистка мёртвых врагов
        var to_remove: Array[CharacterBody2D] = []
        for e in enemies_in_range:
                if not is_instance_valid(e) or e.is_queued_for_deletion():
                        to_remove.append(e)
        for e in to_remove:
                enemies_in_range.erase(e)

        if enemies_in_range.is_empty():
                current_target = null
                return
        # Лазер всегда атакует сильнейшую цель для максимального DPS
        current_target = _target_strongest()


func _target_strongest() -> CharacterBody2D:
        var best: CharacterBody2D = null
        var best_hp: float = -1.0
        for e in enemies_in_range:
                if not is_instance_valid(e):
                        continue
                if e.has_method("get_current_health") and e.get_current_health() > best_hp:
                        best_hp = e.get_current_health()
                        best = e
        return best


func _rotate_turret_toward(target_pos: Vector2) -> void:
        if turret_pivot:
                turret_pivot.look_at(target_pos)


func _draw() -> void:
        if show_range and tower_data:
                var range := tower_data.get_range_at_level(level)
                draw_circle(Vector2.ZERO, range, Color(1.0, 1.0, 1.0, 0.1))
                draw_arc(Vector2.ZERO, range, 0.0, TAU, 64, Color(1.0, 1.0, 1.0, 0.3), 1.0)


func set_show_range(value: bool) -> void:
        show_range = value
        queue_redraw()
```

### scripts/enemy_base.gd

Скрипт врага управляет движением по навигации, получением урона, замедлением и смертью. Ключевые моменты: path_progress отслеживает, как далеко враг прошёл по маршруту (используется башнями для стратегии First/Last). Флаг is_dead предотвращает двойной вызов _die(). Замедление учитывает slow_resistance врага: быстрые враги на 30% устойчивы к замедлению.

```gdscript
extends CharacterBody2D

@export var enemy_data: EnemyData

var current_health: float = 0.0
var path_progress: float = 0.0  # 0..1 насколько далеко по пути
var slow_timer: float = 0.0
var current_slow_factor: float = 1.0
var is_dead: bool = false

signal enemy_died(reward: int)
signal enemy_reached_base(lives_cost: int)
signal health_changed(current: float, max_health: float)

@onready var nav_agent: NavigationAgent2D = $NavigationAgent2D


func _ready() -> void:
        if enemy_data:
                current_health = enemy_data.max_health
                nav_agent.path_desired_distance = 4.0
                nav_agent.target_desired_distance = 8.0
                nav_agent.velocity_computation_mode = NavigationAgent2D.VELOCITY_COMPUTATION_MODE_FLOAT
        add_to_group("enemies")


func _physics_process(delta: float) -> void:
        if is_dead:
                return

        # Обновление замедления
        if slow_timer > 0.0:
                slow_timer -= delta
                if slow_timer <= 0.0:
                        current_slow_factor = 1.0

        if nav_agent.is_navigation_finished():
                _reached_base()
                return

        var next_pos: Vector2 = nav_agent.get_next_path_position()
        var direction: Vector2 = (next_pos - global_position).normalized()
        var speed: float = _get_current_speed()
        velocity = direction * speed

        # Обновление прогресса по пути
        var base_point := get_tree().get_first_node_in_group("base_point") as Marker2D
        if base_point:
                var total_dist := nav_agent.distance_to_target()
                # Приблизительная нормализация прогресса
                path_progress = 1.0 - (total_dist / 1000.0)

        nav_agent.set_velocity(velocity)


func _get_current_speed() -> float:
        if not enemy_data:
                return 0.0
        var speed := enemy_data.move_speed
        # Применяем замедление с учётом устойчивости
        var effective_slow := 1.0 - (1.0 - current_slow_factor) * (1.0 - enemy_data.slow_resistance)
        return speed * effective_slow


func take_damage(amount: float) -> void:
        if is_dead:
                return
        current_health = maxf(current_health - amount, 0.0)
        health_changed.emit(current_health, enemy_data.max_health)
        if current_health <= 0.0:
                _die()


func apply_slow(factor: float, duration: float) -> void:
        if is_dead:
                return
        if enemy_data and enemy_data.slow_resistance >= 1.0:
                return  # Иммунитет к замедлению
        current_slow_factor = minf(current_slow_factor, factor)
        slow_timer = maxf(slow_timer, duration)


func get_path_progress() -> float:
        return path_progress


func get_current_health() -> float:
        return current_health


func _die() -> void:
        if is_dead:
                return
        is_dead = true
        if enemy_data:
                enemy_died.emit(enemy_data.gold_reward)
                EconomyManager.earn(enemy_data.gold_reward)
        remove_from_group("enemies")
        queue_free()


func _reached_base() -> void:
        if is_dead:
                return
        is_dead = true
        if enemy_data:
                enemy_reached_base.emit(enemy_data.lives_cost)
                GameManager.lose_life(enemy_data.lives_cost)
        remove_from_group("enemies")
        queue_free()
```

### scripts/projectile.gd

Скрипт снаряда управляет полётом к цели, столкновением и применением эффектов (урон, область поражения, замедление). Ключевой момент: вместо прямого присвоения свойств на Area2D (`proj.target = ...`), используется метод initialize(), который типобезопасно устанавливает все параметры. Проверка is_instance_valid() предотвращает краш при уничтожении цели до попадания снаряда.

```gdscript
extends Area2D

var target: CharacterBody2D = null
var damage: float = 0.0
var splash_radius: float = 0.0
var slow_factor: float = 1.0
var slow_duration: float = 0.0
var speed: float = 300.0
var lifetime: float = 5.0


func initialize(p_target: CharacterBody2D, p_damage: float, p_splash: float,
                p_slow_factor: float, p_slow_duration: float, p_speed: float) -> void:
        target = p_target
        damage = p_damage
        splash_radius = p_splash
        slow_factor = p_slow_factor
        slow_duration = p_slow_duration
        speed = p_speed


func _physics_process(delta: float) -> void:
        lifetime -= delta
        if lifetime <= 0.0:
                queue_free()
                return

        if not is_instance_valid(target) or target.is_queued_for_deletion():
                queue_free()
                return

        var direction: Vector2 = (target.global_position - global_position).normalized()
        global_position += direction * speed * delta

        # Проверка достаточной близости для попадания
        if global_position.distance_to(target.global_position) < 10.0:
                _on_hit()


func _on_hit() -> void:
        if splash_radius > 0.0:
                _apply_splash_damage()
        else:
                if is_instance_valid(target) and target.has_method("take_damage"):
                        target.take_damage(damage)

        if slow_factor < 1.0:
                _apply_slow_effect()

        queue_free()


func _apply_splash_damage() -> void:
        var enemies := get_tree().get_nodes_in_group("enemies")
        for enemy in enemies:
                if not is_instance_valid(enemy):
                        continue
                var dist := global_position.distance_to(enemy.global_position)
                if dist <= splash_radius and enemy.has_method("take_damage"):
                        var falloff := 1.0 - (dist / splash_radius) * 0.5  # 100% в центре, 50% на краю
                        enemy.take_damage(damage * falloff)


func _apply_slow_effect() -> void:
        if splash_radius > 0.0:
                var enemies := get_tree().get_nodes_in_group("enemies")
                for enemy in enemies:
                        if not is_instance_valid(enemy):
                                continue
                        var dist := global_position.distance_to(enemy.global_position)
                        if dist <= splash_radius and enemy.has_method("apply_slow"):
                                enemy.apply_slow(slow_factor, slow_duration)
        else:
                if is_instance_valid(target) and target.has_method("apply_slow"):
                        target.apply_slow(slow_factor, slow_duration)


func _on_area_entered(area: Area2D) -> void:
        # Резервная обработка столкновений
        if area.is_in_group("hurtbox"):
                var parent := area.get_parent()
                if parent != target and splash_radius <= 0.0:
                        return  # Одноцелевые снаряды поражают только цель
                _on_hit()
```

Магазин башен динамически строит список кнопок из TowerRegistry и обрабатывает выбор башни. При нажатии кнопки проверяется возможность оплаты через EconomyManager, и если средств достаточно, башня размещается в выбранном слоте. Кнопки обновляют состояние (disabled) при изменении баланса.

## 3.4 Persistence Layer — сохранение/загрузка

Persistence Layer отвечает за сериализацию и десериализацию состояния игры. SaveManager координирует процесс, собирая данные от всех менеджеров через методы get_save_data() и восстанавливая через load_save_data(). Данные сохраняются в JSON-формат в пользовательскую директорию (user://), что обеспечивает кроссплатформенность.

### scripts/save_manager.gd (Autoload)

SaveManager сохраняет состояние всех менеджеров в единый JSON-файл. Каждый менеджер предоставляет словарь с данными через get_save_data(), а SaveManager объединяет их в общую структуру с временной меткой. При загрузке данные парсятся из JSON и распределяются по менеджерам через load_save_data(). Ошибки парсинга и доступа к файлам обрабатываются с выводом в консоль.

```gdscript
extends Node

const SAVE_PATH := "user://td_save.json"


func save_game() -> bool:
        var data := {
                "game": GameManager.get_save_data(),
                "economy": EconomyManager.get_save_data(),
                "waves": WaveManager.get_save_data(),
                "timestamp": Time.get_unix_time_from_system(),
        }
        var file := FileAccess.open(SAVE_PATH, FileAccess.WRITE)
        if not file:
                push_error("Не удалось открыть файл сохранения для записи")
                return false
        var json_string := JSON.stringify(data, "\t")
        file.store_string(json_string)
        file.close()
        return true


func load_game() -> bool:
        if not FileAccess.file_exists(SAVE_PATH):
                return false
        var file := FileAccess.open(SAVE_PATH, FileAccess.READ)
        if not file:
                return false
        var json_string := file.get_as_text()
        file.close()
        var json := JSON.new()
        if json.parse(json_string) != OK:
                push_error("Не удалось разобрать файл сохранения")
                return false
        var data: Dictionary = json.data
        if data.has("game"):
                GameManager.load_save_data(data["game"])
        if data.has("economy"):
                EconomyManager.load_save_data(data["economy"])
        if data.has("waves"):
                WaveManager.load_save_data(data["waves"])
        return true


func delete_save() -> void:
        if FileAccess.file_exists(SAVE_PATH):
                DirAccess.remove_absolute(SAVE_PATH)
```

**Интеграция с менеджерами:** Каждый менеджер реализует пару методов get_save_data() / load_save_data(). Это паттерн, который мы видим в GameManager, EconomyManager и WaveManager. Данные сохраняются как плоские словари с простыми типами (int, float, bool, String), которые JSON сериализует без проблем. При добавлении новых менеджеров достаточно добавить их данные в метод save_game().

**Ограничения текущей реализации:** Мы не сохраняем состояние установленных башен и позиций врагов — это потребовало бы более сложной сериализации с сохранением ссылок на TowerData и EnemyData. В расширенной версии можно добавить сохранение массива башен с их типами, позициями и уровнями.

## 3.5 Введение в C++ и GDExtension

GDExtension — это система расширения Godot 4, которая позволяет писать высокопроизводительный код на C++ и интегрировать его в проект как обычные классы Godot. Это не модуль引擎 (который требует перекомпиляции всего движка), а динамическая библиотека, загружаемая во время выполнения. Это означает, что вы можете добавлять C++ классы в проект без изменения исходного кода Godot.

### GDExtension vs GDNative

| Характеристика | GDNative (Godot 3) | GDExtension (Godot 4) |
|---|---|---|
| Доступ к API | Через C-обёртку, ограниченный | Прямой доступ к внутреннему API Godot |
| ABI стабильность | Ограниченная, частые поломки | Стабильный ABI между минорными версиями |
| Производительность | Хорошая, но с накладными расходами | Лучшая (минимальные накладные расходы) |
| Привязка классов | Ручная регистрация, много макросов | Автоматическая через GDCLASS и ClassDB |
| Система сборки | SCons | SCons (рекомендуется) или CMake |
| Статус | Устаревший, не поддерживается | Активно развивается, официальный подход |
| Точка входа | `gdnative_init` | `gdext_init` |

### Настройка среды сборки

Для работы с GDExtension вам понадобятся три компонента:

1. **Компилятор C++:** GCC или Clang на Linux, MSVC (Visual Studio Build Tools) на Windows
2. **Система сборки SCons:** `pip install scons` (требуется Python 3.6+)
3. **godot-cpp:** Библиотека привязок C++ к API Godot, клонируется как подмодуль Git
