В этом проекте вы научились:

- ✅ **C++/GDExtension** — настройка SCons, godot-cpp, .gdextension-файл, _bind_methods(), register_types.cpp → станет основным языком реализации в Проекте 5, где C++ используется с самого начала, а не для оптимизации уже работающего кода
- ✅ **Бенчмарки GDScript vs C++** — измерение реального ускорения: поиск пути 28 мс → 1.1 мс, симуляция снарядов 15 мс → 0.8 мс → навык профилирования будет расширен до Tracy Profiler и бюджета кадра в Проекте 6
- ✅ **Паттерн Strategy** — три стратегии выбора цели (First, Last, Strongest) → будет применён к AI-поведению NPC (Idle, Patrol, Follow, Flee, Attack) в Проекте 5
- ✅ **Data-driven архитектура** — TowerData, EnemyData, WaveData, SpawnGroup как Resource → продолжится в ItemData, QuestData, DialogueData, NPCData с тем же паттерном, но данные будут читаться C++ через GDExtension API
- ✅ **NavigationRegion2D** — навигация врагов через NavigationAgent2D → будет развёрнута в 3D: NavigationRegion3D, NavigationAgent3D, запекание navmesh для каждой зоны отдельно
- ✅ **Гибридная архитектура** — GDScript для UI и менеджеров, C++ для горячего кода → этот подход станет доминирующим в Проектах 5 и 6, где C++ проектируется изначально

В следующем проекте (Проект 5: 3D Приключение) мы добавим:

- ➕ **3D-физика** — CharacterBody3D вместо CharacterBody2D, трансформы вместо позиции, кватернионы вместо углов
- ➕ **Камера от третьего лица** — SpringArm3D с обходом столкновений, сглаживание, кинематографические переходы через FSM
- ➕ **NPC с AI** — конечный автомат (Idle, Patrol, Follow, Flee, Attack) на C++, навигация через NavRegion3D
- ➕ **Диалоговая система** — условные ветки, интеграция с квестами, проверка условий в C++ за O(1)
- ➕ **Система квестов** — QuestData/QuestObjective как Resource, отслеживание целей, награды
- ➕ **Цикл день/ночь** — DirectionalLight3D, расписание NPC, вариация врагов

А также впервые встретимся с:

- ⚡ **Переход в 3D** — всё, что вы знали о 2D, обретёт новое измерение. CharacterBody2D становится CharacterBody3D, Area2D — Area3D, TileMap — MeshInstance3D, Camera2D — Camera3D с SpringArm3D. Навигация переходит от NavigationRegion2D к NavigationRegion3D с запеканием navmesh. Но главное — камера перестаёт быть наблюдателем и становится активной системой: она обходит стены, следует за персонажем с инерцией и переключается в кинематографический режим для кат-сцен. Это качественно иной уровень сложности и свободы.
