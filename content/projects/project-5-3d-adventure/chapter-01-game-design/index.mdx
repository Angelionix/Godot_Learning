## 1.1 Концепция и видение

**Жанр:** 3D Action-Adventure / Third-Person

**Ключевая фантазия:** «Герой, вступающий в забытый мир» — Игрок прибывает в долину, окутанную тьмой. Деревня на краю леса — последний оплот света. Тёмный Лорд в своей башне насылает нежить, и только путник, готовый сражаться, исследовать и помогать, сможет вернуть свет. Каждый квест — шаг к пониманию происходящего, каждый диалог — фрагмент истории, каждый бой — проверка мастерства.

**Целевая длительность сессии:** 20–40 минут активной игры. За это время игрок успеет исследовать одну зону, выполнить 1–2 квеста, победить несколько врагов и, возможно, найти новый предмет или разблокировать путь. Сессия должна ощущаться завершённой: игрок получил награду, продвинулся в истории и сохранил прогресс.

**Почему этот жанр идеален для изучения C++ в 3D:** 3D Приключение объединяет все ключевые подсистемы, каждая из которых имеет свой «порог производительности». Контроллер персонажа и камера работают каждый кадр — критический путь для C++. NPC AI обновляется каждый кадр для 10–20 агентов — C++ обязателен. Диалоговый UI работает по событиям — GDScript идеален. Эта естественная граница делает урок о выборе языка наглядным: студент видит, где C++ необходим, а где избыточен.

## 1.2 Основный игровой цикл

Основной цикл 3D-приключения строится на петле «исследование → бой → диалог → квест → награда → усиление». Игрок исследует мир, сражается с врагами, общается с NPC, берёт и выполняет квесты, получает награды и усиливает персонажа. Каждый виток этого цикла расширяет доступные области и углубляет понимание истории.

```
┌──────────────────────────────────────────────────────────────────┐
│                    ИГРОВОЙ ЦИКЛ 3D ПРИКЛЮЧЕНИЯ                    │
│                                                                   │
│   ┌───────────┐     ┌───────────┐     ┌───────────┐             │
│   │ ИССЛЕДОВА-│────▶│   БОЙ    │────▶│  ДИАЛОГ   │             │
│   │  НИЕ      │     │          │     │           │             │
│   │ Новые     │     │ Враги    │     │ NPC       │             │
│   │ области   │     │ Боссы    │     │ Торговцы  │             │
│   │ Секреты   │     │ Комбо    │     │ Квесты    │             │
│   │ Лут       │     │ Уклонение│     │ История   │             │
│   └───────────┘     └───────────┘     └─────┬─────┘             │
│        ▲                                    │                    │
│        │           ┌───────────┐            │                    │
│        │           │   КВЕСТ   │◀───────────┘                    │
│        │           │           │                                 │
│        │           │ Цели      │     ┌───────────┐              │
│        │           │ Прогресс  │────▶│  НАГРАДА  │              │
│        │           │ Награды   │     │           │              │
│        │           └───────────┘     │ Золото    │              │
│        │                             │ Предметы  │              │
│        │           ┌───────────┐     │ Опыт      │              │
│        └───────────│ УСИЛЕНИЕ  │◀────└───────────┘              │
│                    │           │                                   │
│                    │ Экипировка│                                   │
│                    │ Навыки    │                                   │
│                    │ Репутация │                                   │
│                    └───────────┘                                   │
│                                                                   │
│   Конец: Тёмный Лорд повержен = ПОБЕДА                           │
│          Здоровье = 0 = ПОРАЖЕНИЕ (респаун на точке сохранения)  │

```

**Краткосрочный цикл (секунды):** Заметить врага → уклониться от атаки → нанести комбо → подобрать лут. Этот микроцикл происходит каждые 10–20 секунд в бою и каждые 30–60 секунд при исследовании (подбор предмета, открытие сундука). Визуальная обратная связь: числа урона, вспышки оружия, эффекты частиц при ударах.

**Среднесрочный цикл (минуты):** Найти NPC → получить квест → выполнить цель (убить 5 гоблинов, найти предмет, добраться до локации) → вернуться за наградой. Каждый квест занимает 5–15 минут, обеспечивая ощущение завершённости. Диалоги добавляют контекст: почему эти гоблины — угроза, что за предмет нужен, кто ждёт игрока в новой локации.

**Долгосрочный цикл (вся игра):** Исследовать все 5 зон → выполнить 5 основных квестов → победить Тёмного Лорда → освободить долину. Прогрессия через экипировку (лучшее оружие → больше урона → доступ к более сложным врагам) и через квесты (новые области → новые NPC → новые задания). Цикл дня/ночи добавляет вариативность: ночью враги сильнее, но и лут лучше.

## 1.3 Персонаж и параметры

Контроллер персонажа — основа 3D-приключения. Персонаж перемещается от третьего лица: ввод интерпретируется относительно камеры, прыжок имеет переменную высоту, уклонение даёт кадры неуязвимости, а боевые комбо требуют управления выносливостью. Все параметры настраиваются через инспектор Godot благодаря экспорту C++ свойств через _bind_methods().

### Таблица параметров игрока

| Параметр | Базовое значение | С улучшениями | Описание |
|---|---|---|---|
| max_health | 100 | 200 | Здоровье, увеличивается предметами-улучшениями |
| max_stamina | 100 | 150 | Выносливость, тратится на спринт, уклонение, комбо |
| move_speed | 5.0 m/s | 5.0 m/s | Скорость ходьбы |
| sprint_speed | 8.0 m/s | 9.5 m/s | Скорость бега, тратит 15 выносливости/сек |
| jump_velocity | 4.5 m/s | 5.5 m/s | Начальная скорость прыжка |
| rotation_speed | 10.0 | 10.0 | Скорость поворота персонажа к направлению движения |
| dodge_speed | 10.0 m/s | 10.0 m/s | Скорость уклонения (0.3 сек, 20 выносливости) |
| light_attack_damage | 10 | 15 | Урон лёгкой атаки |
| heavy_attack_damage | 25 | 35 | Урон тяжёлой атаки, тратит 15 выносливости |
| block_reduction | 60% | 75% | Снижение урона при блоке, тратит 10 выносливости/удар |
| stamina_regen | 25/сек | 35/сек | Восстановление выносливости (не в бою: 40/сек) |

### Формулы боя

**Урон лёгкой комбо-цепочки (3 удара):** `total = light × 1.0 + light × 1.2 + light × 1.5`

При базовом уроне 10: 10 + 12 + 15 = 37 урона за комбо (~1.5 сек). Комбо сбрасывается, если следующий удар не следует в течение 0.6 секунды.

**Урон тяжёлой атаки:** `heavy_damage × weapon_multiplier`

Базовый тяжёлый удар наносит 25 урона, но имеет больший кулдаун (0.8 сек) и тратит 15 выносливости. Эффективен против бронированных врагов.

**Уклонение:** Персонаж движется со скоростью `dodge_speed` в течение 0.3 сек. Первые 0.2 сек — кадры неуязвимости (i-frames). Стоимость: 20 выносливости. Кулдаун: 0.5 сек.

**Блок:** Уменьшает входящий урон на `block_reduction`%. Удар по блоку отбрасывает атакующего. Стоимость: 10 выносливости за заблокированный удар. Блок сбивается при нулевой выносливости.

### Выносливость как ресурс

Выносливость — ключевой стратегический ресурс. Спринт, уклонение, тяжёлые атаки и блок — все тратят выносливость. Игрок должен выбирать: уклониться от атаки (20 выносливости) или заблокировать (10 выносливости)? Нанести тяжёлый удар (15 выносливости) или дождаться комбо? Спринт к врагу (15/сек) или подойти шагом? Менеджмент выносливости — разница между мастером боя и новичком.

## 1.4 Структура мира

Мир состоит из 5 зон, соединённых переходами. Каждая зона имеет уникальную атмосферу, набор врагов и сюжетный квест. Прогрессия через мир ограничена квестовыми предметами: чтобы войти в Руины, нужен ключ от Лесного стража; чтобы попасть в Катакомбы — амулет из Руин; чтобы войти в Тёмную башню — все три артефакта.

### Карта мира (5 зон, 15 областей)

| Зона | Области | Враги | Ключевой квест | Переход |
|---|---|---|---|---|
| Деревня (безопасная) | Центральная площадь, Рынок, Дом старейшины | Нет | «Поговори со старейшиной» | → Лес (открыт) |
| Лес | Опушка, Глубокий лес, Поляна гоблинов | Гоблины, Волки | «Очисти лес от гоблинов» | Ключ → Руины |
| Руины | Вход, Зал воинов, Тронный зал | Скелеты-воины, Скелеты-лучники | «Найди амулет в руинах» | Амулет → Катакомбы |
| Катакомбы | Верхний ярус, Нижний ярус, Склеп | Призраки, Скелеты-маги | «Освободи заточённые души» | 3 артефакта → Башня |
| Тёмная башня | Подъём, Тронный зал | Тёмные рыцари | «Победи Тёмного Лорда» | Финальный босс |

### Связи между областями

```
Деревня ──── Лес (Опушка) ──── Глубокий лес ──── Поляна гоблинов
   │                                              │
   │                                         [Ключ от Лесного стража]
   │                                              │
   │                                              ▼
   │                                         Руины (Вход) ──── Зал воинов ──── Тронный зал
   │                                                              │
   │                                                         [Амулет]
   │                                                              │
   │                                                              ▼
   └────────────────────────────────────────────────────── Катакомбы (Верхний ярус)
                                                                │
                                                          Нижний ярус ──── Склеп
                                                                │
                                                          [3 артефакта]
                                                                │
                                                                ▼
                                                          Тёмная башня (Подъём) ──── Тронный зал
```

Каждая область — отдельная сцена, загружаемая при переходе. NavigationRegion3D запекается для каждой области отдельно. NPC расставляются вручную в редакторе, а враги — через Spawner-узлы, управляемые DayNightCycle.

### Навигационная сетка

Параметры запекания navmesh для каждой зоны:

| Параметр | Деревня | Лес | Руины | Катакомбы | Башня |
|---|---|---|---|---|---|
| cell_size | 0.25 | 0.25 | 0.20 | 0.20 | 0.25 |
| cell_height | 0.25 | 0.25 | 0.20 | 0.20 | 0.25 |
| agent_radius | 0.5 | 0.4 | 0.5 | 0.4 | 0.6 |

Деревня использует более крупную сетку (мало препятствий). Катакомбы — мелкую (узкие проходы). Башня — увеличенный радиус агента (крупные враги).

## 1.5 Боевая система

Боевая система в 3D-приключении строится на Hitbox3D/Hurtbox3D — 3D-аналоге 2D-паттерна. Hitbox — это Area3D с коллайдером, которая активно наносит урон при пересечении с Hurtbox3D противника. Hurtbox — это Area3D, которая пассивно принимает урон. Разделение слоёв коллизий гарантирует, что Hitbox игрока не пересекается с Hurtbox игрока.

### Типы врагов и боевые характеристики

| Враг | HP | Урон | Скорость | Дальность обнаружения | Поведение | Награда |
|---|---|---|---|---|---|---|
| Гоблин | 30 | 5 | 3.0 m/s | 8m | Патруль → Преследование → Атака ближняя | 10g,偶尔 зелье |
| Волк | 20 | 8 | 5.0 m/s | 12m | Стая (2–4), атака с флангов | 5g |
| Скелет-воин | 60 | 10 | 2.5 m/s | 6m | Патруль → Блок → Контратака | 15g |
| Скелет-лучник | 25 | 8 (стрела) | 2.0 m/s | 15m | Держит дистанцию, стреляет | 12g |
| Призрак | 40 | 15 | 4.0 m/s | 10m | Телепорт, проходит сквозь стены | 20g |
| Скелет-маг | 35 | 12 (магия) | 2.0 m/s | 12m | AOE-заклинание, отступает | 25g |
| Тёмный рыцарь | 100 | 18 | 2.5 m/s | 8m | Блок, тяжёлая атака, комбо | 40g |
| Тёмный Лорд (Босс) | 500 | 25 | 3.0 m/s | — | 3 фазы, уникальные атаки | 200g + артефакт |

### Анализ баланса: время убийства

**Время убийства (базовое оружие, лёгкие комбо):** `time = enemy_hp / (combo_dps × hit_rate)`

При лёгком комбо (37 урона за 1.5 сек) и hit_rate 80%:
- DPS ≈ 37 / 1.5 × 0.8 = 19.7

| Враг | HP | Время убийства | Опасность |
|---|---|---|---|
| Гоблин | 30 | 1.5 сек | Низкая, но в группе (3+) опасны |
| Волк | 20 | 1.0 сек | Стая окружает, перехватывают уклонение |
| Скелет-воин | 60 | 3.0 сек | Блокирует, нужна тяжёлая атака |
| Скелет-лучник | 25 | 1.3 сек | Прикрывается воинами |
| Призрак | 40 | 2.0 сек | Телепорт делает попадание сложным |
| Тёмный рыцарь | 100 | 5.1 сек | Высокий урон, требует идеального тайминга |

## 1.6 NPC и диалоговая система

NPC — душа приключенческой игры. Они дают квесты, продают предметы, рассказывают историю и создают ощущение живого мира. Каждый NPC имеет расписание, зависящее от времени суток, и набор диалогов, меняющийся в зависимости от прогресса игрока.

### Типы NPC

| NPC | Зона | Роль | Диалоги | Расписание |
|---|---|---|---|---|
| Старейшина | Деревня | Даёт основной квест, рассказывает историю | 5+ вариантов по прогрессу | Площадь днём, дом ночью |
| Кузнец | Деревня | Торговля оружием, улучшения | 3 варианта + торговля | Кузница 6:00–21:00 |
| Травница | Деревня | Торговля зельями, рецепты | 4 варианта + торговля | Лавка 7:00–22:00 |
| Лесной страж | Лес | Даёт квест на ключ, обучает бою | 3 варианта | Поляна, всегда |
| Призрачный мудрец | Катакомбы | Раскрывает историю, даёт подсказки | 5 вариантов | Появляется ночью |
| Торговец-странник | Все зоны | Случайная торговля, редкие предметы | 2 варианта | Перемещается между зонами |

### Диалоговые ветки

Каждый диалог определяется ресурсом DialogueData с массивом DialogueLine. Линии могут содержать choices (варианты ответов), conditions (условия видимости) и on_complete (действия после реплики). Условия проверяются в C++ для скорости: например, `has_item(&"forest_key")` проверяет инвентарь за O(1) через HashMap.

```
Старейшина (первая встреча):
├─ "Добро пожаловать, путник..." → [Рассказать о себе] / [Спросить о долине]
│   ├─ [Рассказать о себе] → "Значит, ты прибыл из-за гор..."
│   └─ [Спросить о долине] → "Тёмный Лорд насылает нежить..."
│       └─ [Предложение помочь] → Квест «Очисти лес от гоблинов» (условие: нет активного квеста)
└─ "Возвращайся, когда будешь готов..." (условие: есть активный квест)
```

| Состояние | Описание | Переходы |
|---|---|---|
| not_started | Квест доступен, но не принят | → in_progress (принять через диалог) |
| in_progress | Квест выполняется | → completed (цели достигнуты), → failed (условие провалено) |
| completed | Квест выполнен, награда получена | Финальное состояние |
| failed | Квест провален | → in_progress (перепрохождение, если разрешено) |

## 1.8 Инвентарь и экипировка

Система инвентаря — центральная подсистема, которая связывает подбор предметов, торговлю, экипировку и квесты. Логика реализуется в C++ для скорости операций, данные — в GDScript Resources для удобства редактирования.

### Типы предметов

| Тип | Описание | Стекуется | Примеры |
|---|---|---|---|
| consumable | Расходуемый, используется однократно | Да (до max_stack) | Зелье лечения, Зелье силы |
| equipment | Экипируемый, занимает слот | Нет | Меч, Доспех, Кольцо |
| quest_item | Квестовый, нельзя выбросить | Нет | Ключ стража, Амулет |
| material | Материал для крафта | Да (до 99) | Железная руда, Травы |

### Слоты экипировки

| Слот | Описание | Бонус |
|---|---|---|
| weapon | Оружие (правая рука) | +урон, +скорость атаки |
| armor | Доспех (тело) | +защита, +max_health |
| accessory | Аксессуар (кольцо/амулет) | Специальные эффекты |

### Таблица оружия

| Оружие | Урон | Скорость атаки | Цена | Источник |
|---|---|---|---|---|
| Ржавый меч | +5 | 1.0× | Стартовое | Начало игры |
| Железный меч | +10 | 1.0× | 80g | Кузнец |
| Улучшенный меч | +15 | 1.1× | 120g | Квест «Ржавый меч» |
| Лук охотника | +8 (дальний) | 0.8× | 100g | Квест «Пропавший охотник» |
| Меч тьмы | +25 | 1.2× | — | Квест «Арена» |

### Формула итогового урона

`final_damage = (base_attack + weapon_bonus) × combo_multiplier × enemy_defense_factor`

- `base_attack` — лёгкий (10) или тяжёлый (25)
- `weapon_bonus` — бонус от экипированного оружия
- `combo_multiplier` — 1.0 / 1.2 / 1.5 для 1/2/3 удара
- `enemy_defense_factor` — 1.0 для гоблинов, 0.7 для скелетов-воинов (блокируют 30%), 0.5 для Тёмного рыцаря (блокирует 50%)

## 1.9 Цикл дня и ночи

Цикл дня/ночи — фоновая система, которая влияет на все остальные подсистемы: враги становятся сильнее ночью, NPC меняют расписание, освещение и атмосфера меняются, появляются ночные враги.

### Параметры цикла

| Параметр | Значение | Описание |
|---|---|---|
| full_cycle_duration | 600 сек (10 мин) | Полный цикл: рассвет → день → закат → ночь |
| day_duration | 360 сек (6 мин) | Дневное время (6:00–18:00) |
| night_duration | 240 сек (4 мин) | Ночное время (18:00–6:00) |
| time_scale | 1.0 | Множитель скорости (для отладки: 10.0) |

### Влияние времени суток

| Аспект | День | Ночь |
|---|---|---|
| Освещение | DirectionalLight3D, яркость 1.0 | DirectionalLight3D, яркость 0.15, синий оттенок |
| Враги | Стандартные | +30% HP, +20% урон, появляются призраки |
| NPC | Активны, на рабочих местах | Спят или дома, торговля недоступна |
| Лут | Стандартный | +50% шанс редкого предмета |
| Навигация | Стандартная | Призраки игнорируют navmesh (фазят сквозь стены) |

## 1.10 Визуальный стиль и звук
