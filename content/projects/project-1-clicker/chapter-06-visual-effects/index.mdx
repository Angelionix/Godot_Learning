Визуальная обратная связь — это то, что превращает простую механику «нажми-получи» в увлекательный игровой процесс. Каждое действие игрока должно сопровождаться заметным визуальным откликом: всплывающие числа, анимация кнопки, частицы, подсветка. Даже простые эффекты значительно улучшают восприятие игры. В этой главе мы реализуем три типа визуальных эффектов: всплывающие числа, анимацию кнопки и частицы конфетти.

## Всплывающие числа

Всплывающие числа — это текстовые элементы, которые появляются при клике, показывают полученную сумму и плавно поднимаются вверх, постепенно затухая. Мы уже реализовали скрипт FloatingText в разделе 5.7, а его создание — в Main.spawn_floating_text(). Напомним ключевые моменты:

```gdscript
func spawn_floating_text(text: String) -> void:
    var floating: Label = FloatingTextScene.instantiate()
    floating.text = text
    floating.position = click_button.global_position + Vector2(
        randf_range(-30, 30),
        randf_range(-20, 10)
    )
    effects_layer.add_child(floating)
```

<Callout type="info" title="Как работает PackedScene">

- **`preload`** загружает сцену на этапе компиляции скрипта, что эффективнее чем `load`, который загружает сцену при первом обращении
- **`instantiate()`** создаёт новый экземпляр сцены
- **`add_child()`** добавляет его в дерево сцены
- **`randf_range`** даёт случайное смещение позиции — если бы все числа появлялись в одной точке, они бы сливались в нечитаемую массу

</Callout>

## Анимация кнопки

При нажатии кнопка уменьшается до 90% размера и плавно возвращается к нормальному. Эта простая анимация создаёт ощущение «нажатия» — как будто кнопка физически утапливается. Реализация уже включена в Main:

```gdscript
func _on_click_button_pressed() -> void:
    GameManager.on_click()
    spawn_floating_text("+%d" % GameManager.click_power)
    click_button.scale = Vector2(0.9, 0.9)  # Мгновенное уменьшение

func _process(delta: float) -> void:
    if click_button.scale.x < 1.0:
        click_button.scale = click_button.scale.move_toward(Vector2.ONE, 5.0 * delta)
```

Мы используем метод `move_toward` класса `Vector2` для плавной интерполяции масштаба к единице. Проверка `click_button.scale.x < 1.0` гарантирует, что мы не выполняем лишнюю работу, когда кнопка уже в нормальном состоянии — это микрооптимизация, которая важна, потому что `_process` вызывается каждый кадр.

## Частицы конфетти

Для особых моментов — разблокировка достижений, покупка дорогих апгрейдов — добавим систему частиц. Godot имеет встроенный узел GPUParticles2D для высокопроизводительных эффектов частиц. Создайте сцену `confetti_particles.tscn` с узлом GPUParticles2D и настройте его следующим образом:

| Параметр | Значение | Описание |
| --- | --- | --- |
| Emission Shape | Point | Частицы испускаются из одной точки |
| Direction | 0, -90 | Начальное направление — вверх |
| Spread | 60 градусов | Разброс направления |
| Gravity | 0, 200 | Гравитация тянет частицы вниз |
| Initial Velocity | 200-400 | Скорость при испускании |
| Amount | 30-50 | Количество частиц |
| Lifetime | 1.5 сек | Время жизни частицы |
| Color Ramp | Gradient | Многоцветный градиент |

<Callout type="tip" title="Создание градиента для конфетти">

В инспекторе GPUParticles2D найдите свойство `Color Ramp`, создайте новый GradientTexture1D, внутри него создайте Gradient и добавьте точки с цветами:

- **Золотой** (#FFD700)
- **Красный** (#FF4444)
- **Зелёный** (#44FF44)
- **Синий** (#4444FF)

Это создаст праздничный, радужный эффект конфетти.

</Callout>

Спавн конфетти при достижении:

```gdscript
func spawn_confetti() -> void:
    var particles: GPUParticles2D = ConfettiScene.instantiate()
    particles.position = click_button.global_position
    particles.emitting = true
    effects_layer.add_child(particles)
    get_tree().create_timer(2.0).timeout.connect(func(): particles.queue_free())
```

<Insight title="Одноразовый таймер без узла Timer">

Метод `get_tree().create_timer()` создаёт одноразовый таймер без необходимости добавлять узел Timer в сцену. Это удобно для разовых отложенных действий. Мы устанавливаем таймер на 2 секунды — это немного больше, чем Lifetime частиц (1.5 сек), чтобы все частицы успели отработать до удаления узла. Подключение лямбда-функции к сигналу timeout — компактный способ задать обработчик прямо в месте вызова.

</Insight>
