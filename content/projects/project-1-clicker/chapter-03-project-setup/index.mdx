Правильная настройка проекта — это фундамент, на котором строится всё остальное. Потратив 10 минут на этом этапе, вы сэкономите часы отладки и переименования в будущем. В этой главе мы шаг за шагом создадим проект, настроим структуру директорий и подготовим все необходимые файлы.

## Создание нового проекта

1. Запустите Godot Engine 4.3. В окне Project Manager нажмите кнопку **«New»** (Создать).
2. В поле **Project Name** введите `ClickerGame`.
3. В поле **Project Path** выберите папку для сохранения проекта.
4. В выпадающем списке **Renderer** выберите **Compatibility** — этот рендерер оптимизирован для 2D-проектов и обеспечивает максимальную совместимость с разными устройствами. Рендерер Forward+ предназначен для 3D-проектов с продвинутым освещением и для нашей 2D-игры избыточен.
5. Нажмите **«Create Folder»** (Создать папку), затем **«Create and Edit»** (Создать и редактировать).

Перед вами откроется редактор Godot с пустой сценой.

## Создание структуры директорий

В панели **FileSystem** (Файловая система) в нижней части редактора нажмите правой кнопкой мыши на корневую папку `res://` и создайте следующие директории:

1. Правый клик на `res://` → **Create New Folder** → введите `scenes`
2. Правый клик на `res://` → **Create New Folder** → введите `scripts`
3. Правый клик на `res://` → **Create New Folder** → введите `assets`
4. Правый клик на `assets` → **Create New Folder** → введите `images`
5. Правый клик на `assets` → **Create New Folder** → введите `fonts`
6. Правый клик на `assets` → **Create New Folder** → введите `audio`
7. Правый клик на `res://` → **Create New Folder** → введите `resources`

После создания структура должна выглядеть так:

```
res://
├── scenes/
├── scripts/
├── assets/
│   ├── images/
│   ├── fonts/
│   └── audio/
└── resources/
```

## Настройка Autoload

Autoload — это механизм Godot для создания глобальных синглтонов. Скрипт, добавленный в Autoload, автоматически инстанцируется при запуске игры и доступен из любого другого скрипта по имени. В нашем проекте два Autoload-скрипта: GameManager и SaveManager.

<Callout type="danger" title="Порядок добавления критически важен">

SaveManager должен быть добавлен **ПОСЛЕ** GameManager, потому что при загрузке SaveManager вызывает методы GameManager. Если SaveManager загрузится первым, GameManager ещё не будет существовать, и мы получим ошибку.

</Callout>

1. Откройте **Project → Project Settings** (Проект → Настройки проекта).
2. Перейдите на вкладку **Autoload**.
3. Нажмите кнопку **«Add»** (Добавить) рядом с полем пути.
4. Для первого автозагрузчика:
   - **Path:** нажмите на иконку папки и выберите `scripts/game_manager.gd` (скрипт будет создан позже, пока просто запомните путь).
   - **Node Name:** `GameManager` (должно совпадать с именем, которое вы будете использовать в коде).
   - Нажмите **Add**.
5. Для второго автозагрузчика:
   - **Path:** `scripts/save_manager.gd`
   - **Node Name:** `SaveManager`
   - Нажмите **Add**.
6. Убедитесь, что GameManager стоит ВЫШЕ SaveManager в списке (порядок сверху вниз — это порядок инициализации). Если нужно, используйте стрелки вверх/вниз для изменения порядка.

<Insight title="Глобальный доступ">

Теперь из любого скрипта вы можете обратиться к `GameManager.currency` или `SaveManager.save_game()` без необходимости получать ссылку на эти объекты.

</Insight>

## Первый запуск сцены

В Godot всё строится вокруг концепции сцен и узлов. Сцена (Scene) — это коллекция узлов (Nodes), организованных в древовидную структуру. Каждый узел выполняет определённую функцию: отображение спрайта, воспроизведение звука, обработку физики и так далее. Дерево узлов начинается с корневого узла, и дочерние узлы наследуют позицию и трансформации от родительских.

Создайте нашу первую сцену: нажмите **«2D Scene»** в панели сцены, чтобы создать корневой узел типа Node2D. Переименуйте его в «Main». Сохраните сцену как `scenes/main.tscn`. Эта сцена будет главным контейнером для всех элементов нашей игры.
