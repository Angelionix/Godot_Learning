Добро пожаловать в первый проект нашего курса по разработке игр на Godot Engine! В этом проекте мы создадим кликер/idle-игру с нуля, изучая основы GDScript и ключевые концепции движка Godot 4. Кликер-игра — это идеальный стартовый проект, поскольку он позволяет освоить фундаментальные механизмы: обработку ввода, работу с переменными и таймерами, создание пользовательского интерфейса и систему сохранения прогресса. Все эти навыки станут фундаментом для более сложных проектов в последующих частях курса.

Наш подход к обучению строится на практике: каждая новая концепция вводится ровно тогда, когда она нужна для реализации конкретной функции игры. Вы не просто читаете теорию — вы сразу видите, как каждый кусок кода работает в реальном проекте. К концу этого проекта у вас будет полностью функциональная кликер-игра с системой апгрейдов, автокликерами, визуальными эффектами и сохранением прогресса между сессиями.

Для работы вам потребуется установленный Godot Engine версии 4.3 или выше. Все примеры кода протестированы на Godot 4.3. Рекомендуется использовать редактор кода, встроенный в Godot, либо Visual Studio Code с расширением для GDScript.

## Цели обучения

По завершении этого проекта вы сможете:

1. Создавать и структурировать проект Godot с правильной организацией файлов
2. Использовать типизированные переменные и функции в GDScript для предотвращения ошибок
3. Проектировать и реализовывать систему апгрейдов с экспоненциальным ростом стоимости
4. Применять сигналы Godot для слабосвязанной коммуникации между компонентами
5. Работать с таймерами для реализации пассивного дохода (idle-механика)
6. Создавать динамические UI-элементы и обновлять их через сигналы
7. Сериализовать и десериализовать состояние игры в JSON-формат
8. Реализовывать оффлайн-прогресс с ограничением по времени
9. Использовать PackedScene для динамического создания визуальных эффектов
10. Настраивать Autoload-синглтоны для глобального доступа к подсистемам

## Временная оценка

Ориентировочное время выполнения проекта: **15–20 часов**, включая изучение теории, написание кода, отладку и эксперименты. Не спешите — каждая концепция, освоенная здесь, будет использоваться в последующих проектах курса.

## Почему именно кликер?

Этот проект выбран первым не случайно. Кликер-игра покрывает практически все фундаментальные подсистемы, с которыми вы столкнётесь при разработке любой игры:

- **Обработка ввода** пользователя
- **Управление игровым состоянием**
- **Таймеры** и периодические события
- **Пользовательский интерфейс** с динамическим обновлением
- **Визуальные эффекты** и частицы
- **Персистентность данных** (сохранение и загрузка)

При этом кликер не требует сложной физики, искусственного интеллекта или работы со спрайтами — это позволяет сфокусироваться на архитектуре и логике, не отвлекаясь на визуальные сложности. Каждый механизм, реализованный в этом проекте, является строительным блоком для более крупных проектов.
