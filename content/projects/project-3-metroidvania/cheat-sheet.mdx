### FSM (Конечный автомат)
| Действие | Код | Раздел |
|---|---|---|
| Базовое состояние | `class_name PlayerState extends Node; signal transition_requested(target: String)` | P3 §2.3 |
| Переключение | `transition_requested.emit("run")` из состояния | P3 §2.5 |
| Обработка | `StateMachine._on_transition_requested(): current_state.exit(); _set_state(target)` | P3 §2.5 |
| enter/exit | `func enter() -> void:` / `func exit() -> void:` — инициализация и очистка | P3 §2.5 |
| physics_update | `func physics_update(delta: float) -> void:` — логика в _physics_process | P3 §2.5 |
| update | `func update(delta: float) -> void:` — логика в _process | P3 §2.5 |
