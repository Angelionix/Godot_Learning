В этом проекте вы научились:

- ✅ **Конечный автомат (FSM)** — девять состояний персонажа и босс с фазами → понадобится в Проекте 4 для управления состояниями менеджера волн (Idle → Spawning → Active) и поведения врагов
- ✅ **Инвентарь и предметы** — InventoryManager с ключами, расходуемыми и улучшениями → будет расширен до гибридной C++/GDScript системы инвентаря с HashMap для O(1) доступа и BoneAttachment3D для экипировки
- ✅ **Система сохранения** — SaveManager с отслеживанием world_state (убитые враги, собранные предметы) → станет основой для сериализации гибридных C++/GDScript данных через to_dict()/from_dict()
- ✅ **Hitbox/Hurtbox** — боевая система на Area2D с отбрасыванием и i-frames → будет перенесена в 3D (Area3D) в Проекте 5
- ✅ **Autoload-менеджеры** — пять глобальных синглтонов, общающихся через сигналы → паттерн сохранится, но часть менеджеров будет реализована на C++ через GDExtension
- ✅ **Data-driven дизайн** — AbilityData, ItemData, EnemyData как Resource → продолжится в TowerData, WaveData, SpawnGroup с тем же паттерном

В следующем проекте (Проект 4: Tower Defense) мы добавим:

- ➕ **GDExtension** — настройка среды сборки C++: SCons, godot-cpp, файл .gdextension, _bind_methods()
- ➕ **C++ PathFinder** — реализация алгоритма A* на C++ для поиска пути врагов, бенчмарки GDScript vs C++
- ➕ **C++ ProjectileSimulator** — пакетная обработка снарядов на C++ вместо поштучной на GDScript
- ➕ **Паттерн Strategy** — три стратегии выбора цели (First, Last, Strongest) для башен
- ➕ **NavigationRegion2D** — навигация врагов по маршруту через NavigationAgent2D

А также впервые встретимся с:

- ⚡ **Переход на C++** — впервые в курсе мы выйдем за пределы GDScript. Вы увидите, как одна и та же задача (поиск пути) выполняется на GDScript за 28 мс и на C++ за 1.1 мс — разница в 26 раз. Это не просто оптимизация, это качественный скачок: задачи, которые были невозможны в реальном времени на GDScript, становятся тривиальными на C++. После этого проекта вы будете знать, когда C++ необходим, а когда GDScript достаточен.
