## Связь с проектом 3

В проекте 3 (Metroidvania) мы перейдём к ещё более сложной архитектуре. Концепции, освоенные в этом проекте, получат дальнейшее развитие:

- **CharacterBody2D** будет использоваться для платформерной физики (гравитация, прыжки, стенное скольжение) вместо плавающего режима. Метод `move_and_slide()` будет обрабатывать наклонные поверхности и односторонние платформы.
- **Сигналы** станут основой конечного автомата персонажа: переходы между состояниями (Idle, Run, Jump, Attack) будут реализованы через сигналы, обеспечивая слабую связанность между состояниями.
- **PackedScene** будет применяться для предметов и способностей: каждый предмет в мире Metroidvania — это отдельная сцена, которую можно размещать в редакторе.
- **Resource** будет описывать данные уровней, предметов и способностей — аналогично WeaponData и EnemyData в этом проекте.
- **Object Pool** будет применён к системе снарядов и эффектов — паттерн, который вы уже освоили, будет работать в новом контексте.
- **Наследование сцен** будет использоваться для создания вариаций врагов и предметов, расширяя подход из enemy_base.gd.
