## 5.1 WeaponData — модель данных оружия

`WeaponData` — это Resource, описывающий все параметры оружия. Использование Resource для данных оружия — ключевое архитектурное решение: оно позволяет создавать новые виды оружия без написания кода, просто создавая новые `.tres`-файлы в редакторе. Геймдизайнер может настраивать баланс (скорострельность, урон, разброс), не открывая ни одного скрипта. Это особенно важно в шутере, где баланс — это итеративный процесс: значение скорости пули может меняться десятки раз в ходе плейтестинга.

Каждое свойство `WeaponData` имеет тип и значение по умолчанию. Это гарантирует, что даже если в `.tres`-файле не указано какое-то поле, оно получит осмысленное значение, а не `null`. Типизированные свойства также обеспечивают автодополнение в редакторе и раннее обнаружение ошибок.

Создайте файл `scripts/weapon_data.gd`:

```gdscript
# scripts/weapon_data.gd
class_name WeaponData
extends Resource

enum WeaponType {
    SINGLE,       # Одиночный выстрел
    SPREAD,       # Веерная стрельба
    RAPID,        # Автоматическая стрельба
    HOMING,       # Самонаводящиеся снаряды
}

@export var weapon_name: String = "Pistol"
@export var type: WeaponType = WeaponType.SINGLE
@export var fire_rate: float = 0.3          # Секунд между выстрелами
@export var damage: int = 1                 # Урон за снаряд
@export var bullet_speed: float = 600.0     # Пикселей/сек
@export var bullet_count: int = 1           # Количество снарядов за выстрел
@export var spread_angle: float = 0.0       # Разброс в градусах (для SPREAD)
@export var bullet_scene: PackedScene       # Сцена снаряда
@export var muzzle_offset: Vector2 = Vector2.ZERO  # Смещение от GunPosition
@export var auto_fire: bool = false         # Зажимать кнопку или нажимать


func get_spread_angles() -> Array[float]:
    """Возвращает массив углов для каждого снаряда в веере."""
    var angles: Array[float] = []
    if bullet_count == 1:
        angles.append(0.0)
        return angles

    var half_spread: float = spread_angle / 2.0
    var step: float = spread_angle / max(bullet_count - 1, 1)
    for i in range(bullet_count):
        angles.append(-half_spread + step * i)
    return angles
```

<Callout type="info" title="Как создать .tres-файл в редакторе">

1. В FileSystem панели нажмите правой кнопкой на папку `resources/weapons/`
2. Выберите **Create New → Resource**
3. В появившемся диалоге найдите `WeaponData` и выберите его
4. Назовите файл, например, `pistol.tres`
5. В Inspector настройте параметры: `weapon_name = "Pistol"`, `fire_rate = 0.3`, `damage = 1` и т.д.
6. Повторите для `machinegun.tres` (fire_rate = 0.08, auto_fire = true), `spreadgun.tres` (bullet_count = 5, spread_angle = 30)

</Callout>

Метод `get_spread_angles()` вычисляет углы для каждого снаряда при веерной стрельбе. Для пяти снарядов с `spread_angle = 30` он вернёт `[-15, -7.5, 0, 7.5, 15]` — симметричный веер относительно центрального направления. Вычисление вынесено в WeaponData, а не в Player, потому что это чисто данные: разное оружие может иметь разное количество снарядов и разный разброс, и эти параметры должны настраиваться в Resource.

<Insight title="Почему PackedScene внутри Resource?">

Свойство `bullet_scene: PackedScene` позволяет разному оружию использовать разные снаряды. Пистолет стреляет обычными пулями, лазер — длинными узкими снарядами, а ракетница — самонаводящимися ракетами. Каждая из этих «пуль» — отдельная сцена со своим скриптом, спрайтом и формой столкновения. Паттерн «Strategy через данные» позволяет менять поведение оружия, просто подставляя другую сцену, без единой строки нового кода.

</Insight>

## 5.2 Bullet — снаряд

Bullet — это Area2D-объект, который движется по прямой и регистрирует столкновения. Почему Area2D, а не CharacterBody2D? Потому что снаряду не нужна физика: он не должен отскакивать от стен, не должен скользить вдоль поверхностей и не должен реагировать на гравитацию. Area2D легче по производительности и генерирует сигналы столкновений автоматически, что идеально для «hit-and-forget» объектов.

Важно понимать жизненный цикл снаряда: он берётся из пула (`ObjectPool.get_instance()`), активируется (устанавливается позиция, направление, включается CollisionShape2D), летит, при столкновении наносит урон и возвращается в пул. Он никогда не удаляется через `queue_free()` — возврат в пул происходит через `ObjectPool.release()`. Это устраняет фрагментацию памяти и задержки при частом создании/удалении объектов.

Создайте файл `scripts/bullet.gd`:

```gdscript
# scripts/bullet.gd
extends Area2D

var direction: Vector2 = Vector2.UP
var speed: float = 600.0
var damage: int = 1
var _is_active: bool = false

@onready var collision_shape: CollisionShape2D = $CollisionShape2D
@onready var visible_on_screen: VisibleOnScreenNotifier2D = $VisibleOnScreenNotifier2D


func _ready() -> void:
    area_entered.connect(_on_area_entered)
    if visible_on_screen:
        visible_on_screen.screen_exited.connect(_on_screen_exited)


func _physics_process(delta: float) -> void:
    if not _is_active:
        return
    position += direction * speed * delta


func activate(pos: Vector2, dir: Vector2, spd: float, dmg: int) -> void:
    """Инициализация снаряда при извлечении из пула."""
    global_position = pos
    direction = dir.normalized()
    speed = spd
    damage = dmg
    _is_active = true
    # Включаем форму столкновения (отложенно, чтобы избежать конфликтов)
    if collision_shape:
        collision_shape.set_deferred("disabled", false)
    visible = true


func deactivate() -> void:
    """Деактивация снаряда перед возвратом в пул."""
    _is_active = false
    visible = false
    if collision_shape:
        collision_shape.set_deferred("disabled", true)


func _on_area_entered(area: Area2D) -> void:
    if not _is_active:
        return
    # Проверяем, что попали во врага (у него должен быть метод take_damage)
    var parent: Node = area.get_parent()
    if parent.has_method("take_damage"):
        parent.take_damage(damage)
    _return_to_pool()


func _on_screen_exited() -> void:
    """Снаряд вылетел за экран — возвращаем в пул."""
    if _is_active:
        _return_to_pool()


func _return_to_pool() -> void:
    deactivate()
    if ObjectPool:
        ObjectPool.release(self)
```

<Callout type="warning" title="set_deferred — зачем отложенное отключение?">

Вызов `collision_shape.disabled = true` напрямую в момент обработки столкновения может вызвать проблемы: физический движок Godot всё ещё обрабатывает текущий кадр столкновений, и немедленное изменение формы приведёт к непредсказуемому поведению. `set_deferred("disabled", true)` откладывает изменение до конца физического кадра, гарантируя корректность. Аналогично при активации: `set_deferred("disabled", false)` предотвращает ложные срабатывания в том же кадре, когда снаряд был перемещён на новую позицию.

</Callout>

Коллизионные слои для Bullet настраиваются в сцене `bullet.tscn`:

- **Layer**: `PlayerBullet` (слой 2) — чтобы враги могли обнаруживать этот снаряд
- **Mask**: `Enemy` (слой 3) — чтобы снаряд обнаруживал врагов

Если снаряд принадлежит врагу (EnemyBullet), в его сцене слои будут другими: layer = EnemyBullet (4), mask = Player (1). Это разделение гарантирует, что вражеские снаряды не попадают по другим врагам, а снаряды игрока не попадают по самому игроку.

## 5.3 Player — корабль игрока

Player — это центральный объект игры, и его скрипт самый сложный в этом разделе. Он объединяет движение, стрельбу, систему здоровья, щит и ограничение границ экрана. Все эти системы работают в `_physics_process()`, потому что движение через `move_and_slide()` требует фиксированного шага физики.

Ключевое архитектурное решение: Player содержит массив `WeaponData`, а не хардкодит оружие. Это позволяет менять оружие во время игры (подобранный бонус заменяет текущее оружие) и добавлять новые типы оружия без изменения кода Player. WeaponData выступает в роли паттерна Strategy: Player вызывает `shoot()` одинаково, но поведение стрельбы определяется данными.

Создайте файл `scripts/player.gd`:

```gdscript
# scripts/player.gd
extends CharacterBody2D

signal health_changed(new_health: int, max_health: int)
signal died
signal weapon_changed(weapon: WeaponData)

@export var max_health: int = 5
@export var move_speed: float = 300.0
@export var weapons: Array[WeaponData] = []
@export var invincibility_time: float = 1.0

var current_health: int = 5
var current_weapon_index: int = 0
var _fire_cooldown: float = 0.0
var _is_invincible: bool = false
var _invincibility_timer: float = 0.0
var _shield_active: bool = false
var _shield_hits: int = 0

@onready var hitbox: Area2D = $Hitbox
@onready var gun_position: Marker2D = $GunPosition
@onready var shield_visual: Node2D = $ShieldVisual
@onready var engine_particles: GPUParticles2D = $EngineParticles

# Границы экрана — устанавливаются извне при инициализации
var _screen_rect: Rect2 = Rect2(0, 0, 1152, 648)


func _ready() -> void:
    current_health = max_health
    if hitbox:
        hitbox.area_entered.connect(_on_hitbox_area_entered)
    shield_visual.visible = false
    health_changed.emit(current_health, max_health)


func _physics_process(delta: float) -> void:
    _handle_movement(delta)
    _handle_shooting(delta)
    _handle_invincibility(delta)
    _clamp_to_screen()
    move_and_slide()
    _update_engine_particles()


func _handle_movement(_delta: float) -> void:
    var input: Vector2 = Input.get_vector("move_left", "move_right", "move_up", "move_down")
    velocity = input * move_speed


func _handle_shooting(delta: float) -> void:
    _fire_cooldown -= delta
    if _fire_cooldown > 0.0:
        return

    var weapon: WeaponData = _get_current_weapon()
    if weapon == null:
        return

    var should_fire: bool = false
    if weapon.auto_fire:
        should_fire = Input.is_action_pressed("shoot")
    else:
        should_fire = Input.is_action_just_pressed("shoot")

    if should_fire:
        _fire_weapon(weapon)
        _fire_cooldown = weapon.fire_rate


func _get_current_weapon() -> WeaponData:
    if weapons.is_empty():
        return null
    var idx: int = wrapi(current_weapon_index, 0, weapons.size())
    return weapons[idx]


func _fire_weapon(weapon: WeaponData) -> void:
    if not weapon.bullet_scene:
        return

    var angles: Array[float] = weapon.get_spread_angles()
    var base_rotation: float = -PI / 2.0  # Вверх

    for angle_deg in angles:
        var angle_rad: float = base_rotation + deg_to_rad(angle_deg)
        var bullet_dir: Vector2 = Vector2.from_angle(angle_rad)

        var bullet: Node2D = ObjectPool.get_instance(weapon.bullet_scene)
        if bullet and bullet.has_method("activate"):
            var spawn_pos: Vector2 = gun_position.global_position + weapon.muzzle_offset.rotated(angle_rad)
            bullet.activate(spawn_pos, bullet_dir, weapon.bullet_speed, weapon.damage)

    AudioManager.play_sfx("shoot")


func take_damage(amount: int) -> void:
    if _is_invincible:
        return

    if _shield_active:
        _shield_hits -= 1
        if _shield_hits <= 0:
            _shield_active = false
            shield_visual.visible = false
        AudioManager.play_sfx("shield_hit")
        return

    current_health = max(current_health - amount, 0)
    health_changed.emit(current_health, max_health)
    _start_invincibility()
    AudioManager.play_sfx("player_hit")

    if current_health <= 0:
        die()


func heal(amount: int) -> void:
    current_health = mini(current_health + amount, max_health)
    health_changed.emit(current_health, max_health)


func activate_shield(hits: int) -> void:
    _shield_active = true
    _shield_hits = hits
    shield_visual.visible = true


func switch_weapon(index: int) -> void:
    if index >= 0 and index < weapons.size():
        current_weapon_index = index
        weapon_changed.emit(weapons[index])


func add_weapon(weapon: WeaponData) -> void:
    weapons.append(weapon)
    current_weapon_index = weapons.size() - 1
    weapon_changed.emit(weapon)


func _start_invincibility() -> void:
    _is_invincible = true
    _invincibility_timer = invincibility_time
    # Мигание спрайта — модуляция через tween
    var tween: Tween = create_tween().set_loops(3)
    tween.tween_property($Sprite2D, "modulate:a", 0.2, 0.15)
    tween.tween_property($Sprite2D, "modulate:a", 1.0, 0.15)


func _handle_invincibility(delta: float) -> void:
    if not _is_invincible:
        return
    _invincibility_timer -= delta
    if _invincibility_timer <= 0.0:
        _is_invincible = false
        $Sprite2D.modulate.a = 1.0


func _clamp_to_screen() -> void:
    global_position.x = clampf(global_position.x, _screen_rect.position.x + 20, _screen_rect.end.x - 20)
    global_position.y = clampf(global_position.y, _screen_rect.position.y + 20, _screen_rect.end.y - 20)


func _update_engine_particles() -> void:
    if engine_particles:
        engine_particles.emitting = velocity.length_squared() > 100.0


func _on_hitbox_area_entered(area: Area2D) -> void:
    # Вражеский снаряд
    if area is Area2D and area.has_method("activate"):
        take_damage(1)
        area._return_to_pool()
    # Бонус
    elif area.has_method("collect"):
        area.collect(self)


func die() -> void:
    died.emit()
    AudioManager.play_sfx("explosion_player")
    ObjectPool.get_instance(preload("res://scenes/explosion.tscn"))
    # Деактивация вместо queue_free — пул управляет жизненным циклом
    visible = false
    set_physics_process(false)
```

<Callout type="info" title="Разбор ключевых моментов Player">

- **`_handle_movement()`** использует `Input.get_vector()`, который автоматически нормализует диагональное движение и обрабатывает геймпад. Значение `move_speed` задаёт скорость в пикселях/сек.
- **`_fire_weapon()`** использует `get_spread_angles()` из WeaponData для веерной стрельбы. `Vector2.from_angle()` создаёт вектор направления из угла, что удобнее, чем ручные вычисления синуса/косинуса.
- **`take_damage()`** сначала проверяет щит — если щит активен, урон поглощается им, а здоровье не уменьшается. Это создаёт двухуровневую защиту.
- **`_clamp_to_screen()`** ограничивает позицию игрока границами экрана, не давая кораблю вылететь за пределы видимой области. Отступ в 20 пикселей предотвращает частичное исчезновение спрайта.
- **`_start_invincibility()`** использует Tween для мигания спрайта — визуальный сигнал неуязвимости. Tween автоматически удаляется после завершения.

</Callout>

<Insight title="MOTION_MODE_FLOATING — почему не дефолтный режим?">

По умолчанию CharacterBody2D использует `MOTION_MODE_GROUNDED`, который оптимизирован для платформеров: он добавляет гравитацию, поддержку «пола» и скольжение по стенам. В космическом шутере всё это лишнее — нам нужна полная свобода движения в 2D. `MOTION_MODE_FLOATING` убирает все эти допущения и делает `move_and_slide()` простым: `velocity` применяется напрямую, столкновения скользят вдоль поверхностей. Установите этот режим в инспекторе Player: **Motion Mode → Floating**.

</Insight>

## 5.4 ObjectPool — пул объектов

ObjectPool — это один из самых важных менеджеров в экшен-игре. В бою на экране одновременно могут находиться десятки снарядов, взрывов и врагов. Без пула каждый выстрел создавал бы новый узел через `instantiate()`, а каждое попадание удаляло бы его через `queue_free()`. Это приводит к фрагментации памяти и микрозадержкам, особенно заметным на мобильных устройствах. ObjectPool заранее создаёт объекты и переиспользует их, устраняя накладные расходы на аллокацию.

Паттерн прост: при запуске игры мы «прогреваем» пул — создаём N экземпляров каждого типа и прячем их. Когда нужен объект, мы берём его из пула, настраиваем и показываем. Когда объект больше не нужен, мы его прячем и возвращаем в пул. Никаких `instantiate()` и `queue_free()` в рантайме.

Создайте файл `scripts/object_pool.gd`:

```gdscript
# scripts/object_pool.gd
extends Node

# Конфигурация: какие сцены и в каком количестве пулировать
# Заполняется в _ready() или через инспектор
@export var pool_configs: Array[Dictionary] = []

# Внутреннее хранилище: путь сцены → массив свободных узлов
var _pools: Dictionary = {}
# Кэш загруженных сцен: путь → PackedScene
var _scene_cache: Dictionary = {}


func _ready() -> void:
    _warm_pools()


func _warm_pools() -> void:
    """Предварительное создание объектов для каждого типа."""
    for config in pool_configs:
        var scene_path: String = config.get("scene", "")
        var count: int = config.get("count", 10)
        if scene_path.is_empty():
            continue
        var scene: PackedScene = _get_scene(scene_path)
        if scene == null:
            continue
        _pools[scene_path] = []
        for i in range(count):
            var instance: Node = scene.instantiate()
            instance.set_process(false)
            instance.set_physics_process(false)
            if "visible" in instance:
                instance.visible = false
            # Деактивируем CollisionShape2D у потомков
            _disable_collisions(instance)
            add_child(instance)
            _pools[scene_path].append(instance)


func get_instance(scene: PackedScene) -> Node2D:
    """Получить экземпляр из пула или создать новый."""
    if scene == null:
        push_error("ObjectPool: scene is null")
        return null

    var scene_path: String = scene.resource_path
    if scene_path.is_empty():
        # Сцена создана программно — используем instantiate
        var fallback: Node = scene.instantiate()
        add_child(fallback)
        return fallback as Node2D

    # Захэшируем сцену, если ещё не видели
    if not _pools.has(scene_path):
        _pools[scene_path] = []
        _scene_cache[scene_path] = scene

    var pool: Array = _pools[scene_path]

    # Ищем неактивный объект
    for obj in pool:
        if not obj.is_inside_tree() or not obj.visible:
            _activate_object(obj)
            return obj as Node2D

    # Пул исчерпан — создаём дополнительный объект
    var new_instance: Node = scene.instantiate()
    add_child(new_instance)
    pool.append(new_instance)
    _activate_object(new_instance)
    return new_instance as Node2D


func release(instance: Node) -> void:
    """Вернуть объект в пул."""
    if instance == null or not is_instance_valid(instance):
        return
    instance.set_process(false)
    instance.set_physics_process(false)
    if "visible" in instance:
        instance.visible = false
    _disable_collisions(instance)
    # Не удаляем — оставляем в дереве для переиспользования


func _activate_object(obj: Node) -> void:
    """Активировать объект перед использованием."""
    obj.set_process(true)
    obj.set_physics_process(true)
    if "visible" in obj:
        obj.visible = true
    _enable_collisions(obj)


func _get_scene(path: String) -> PackedScene:
    """Загрузить и закэшировать PackedScene."""
    if _scene_cache.has(path):
        return _scene_cache[path]
    var scene: PackedScene = load(path) as PackedScene
    if scene:
        _scene_cache[path] = scene
    return scene


func _disable_collisions(node: Node) -> void:
    """Отключить все CollisionShape2D у узла и его потомков."""
    for child in node.get_children():
        if child is CollisionShape2D:
            child.set_deferred("disabled", true)
        elif child is Area2D:
            child.set_deferred("monitoring", false)
            child.set_deferred("monitorable", false)


func _enable_collisions(node: Node) -> void:
    """Включить все CollisionShape2D у узла и его потомков."""
    for child in node.get_children():
        if child is CollisionShape2D:
            child.set_deferred("disabled", false)
        elif child is Area2D:
            child.set_deferred("monitoring", true)
            child.set_deferred("monitorable", true)


func get_pool_size(scene: PackedScene) -> int:
    """Отладочный метод — размер пула для данной сцены."""
    var path: String = scene.resource_path
    if _pools.has(path):
        return _pools[path].size()
    return 0


func get_active_count(scene: PackedScene) -> int:
    """Отладочный метод — количество активных объектов."""
    var path: String = scene.resource_path
    if not _pools.has(path):
        return 0
    var count: int = 0
    for obj in _pools[path]:
        if obj.visible:
            count += 1
    return count
```

<Callout type="tip" title="Настройка pool_configs в инспекторе">

Добавьте ObjectPool как Autoload (см. раздел 5.10) и настройте `pool_configs` прямо в `object_pool.gd` или программно. Пример конфигурации:

```
[
    {"scene": "res://scenes/bullet.tscn", "count": 50},
    {"scene": "res://scenes/enemy_bullet.tscn", "count": 30},
    {"scene": "res://scenes/explosion.tscn", "count": 15},
    {"scene": "res://scenes/pickup.tscn", "count": 10},
]
```

Пули — самый частый объект, поэтому их пул самый большой. Взрывы и бонусы — более редкие, их пулы меньше.

</Callout>

<Insight title="Почему пул растёт динамически?">

Метод `get_instance()` создаёт дополнительный объект, если пул исчерпан, вместо того чтобы возвращать `null`. Это решение основано на практике: в экшен-игре невозможно точно предсказать пиковую нагрузку. На босс-фазе с плотным огнём может понадобиться больше снарядов, чем при обычной волне. Динамический рост гарантирует, что игра никогда не «сломается» из-за нехватки объектов, при этом стартовый пул обеспечивает быстрый старт без фризов.

</Insight>

## 5.5 EnemyBase и наследники

EnemyBase — это базовый скрипт для всех врагов, реализующий паттерн Template Method. Базовый класс определяет «скелет» поведения в `_physics_process()`: движение → проверка стрельбы → проверка границ. Конкретные шаги (как именно двигаться, как стрелять) переопределяются в дочерних классах через виртуальные методы `move_behavior()` и `fire_behavior()`. Это устраняет дублирование: каждый враг разделяет логику здоровья, получения урона, смерти и возврата в пул, но реализует уникальное поведение.

Создайте файл `scripts/enemy_base.gd`:

```gdscript
# scripts/enemy_base.gd
extends CharacterBody2D

signal died(points: int)

@export var data: EnemyData

var health: int = 3
var _is_active: bool = false
var _fire_timer: float = 0.0
var _elapsed_time: float = 0.0
var _screen_rect: Rect2 = Rect2(0, 0, 1152, 648)

@onready var hitbox: Area2D = $Hitbox
@onready var gun_position: Marker2D = $GunPosition


func _ready() -> void:
    if hitbox:
        hitbox.area_entered.connect(_on_hitbox_area_entered)


func _physics_process(delta: float) -> void:
    if not _is_active:
        return

    _elapsed_time += delta

    # Template Method: дочерние классы переопределяют поведение
    velocity = move_behavior(delta)
    fire_behavior(delta)
    move_and_slide()

    # Удаление при вылете далеко за экран
    if global_position.y > _screen_rect.end.y + 100:
        _return_to_pool()


func move_behavior(_delta: float) -> Vector2:
    """Виртуальный метод — переопределяется в наследниках."""
    return Vector2.DOWN * 100.0


func fire_behavior(_delta: float) -> void:
    """Виртуальный метод — переопределяется в наследниках."""
    pass


func activate(pos: Vector2, enemy_data: EnemyData) -> void:
    """Инициализация врага при спавне."""
    data = enemy_data
    global_position = pos
    health = data.max_health if data else 3
    _is_active = true
    _fire_timer = randf_range(0.5, 2.0)
    _elapsed_time = 0.0
    visible = true
    set_physics_process(true)


func take_damage(amount: int) -> void:
    if not _is_active:
        return
    health -= amount
    if health <= 0:
        die()


func die() -> void:
    _is_active = false
    var points: int = data.points if data else 10
    died.emit(points)

    # Спавн взрыва
    var explosion_scene: PackedScene = preload("res://scenes/explosion.tscn")
    var explosion: Node2D = ObjectPool.get_instance(explosion_scene)
    if explosion:
        explosion.global_position = global_position

    # Случайный дроп бонуса
    _try_spawn_pickup()

    AudioManager.play_sfx("explosion_enemy")
    _return_to_pool()


func _try_spawn_pickup() -> void:
    var drop_chance: float = data.drop_chance if data else 0.15
    if randf() <= drop_chance:
        var pickup_scene: PackedScene = preload("res://scenes/pickup.tscn")
        var pickup: Node2D = ObjectPool.get_instance(pickup_scene)
        if pickup and pickup.has_method("activate"):
            pickup.activate(global_position)


func _on_hitbox_area_entered(area: Area2D) -> void:
    """Снаряд игрока попал во врага."""
    if area.has_method("activate") and area._is_active:
        var damage: int = area.damage if "damage" in area else 1
        take_damage(damage)
        area._return_to_pool()


func _return_to_pool() -> void:
    _is_active = false
    visible = false
    set_physics_process(false)
    if ObjectPool:
        ObjectPool.release(self)
```

Теперь создадим конкретных наследников. Каждый из них переопределяет `move_behavior()` и/или `fire_behavior()`.

**EnemyFighter** — базовый враг с зигзагообразным движением:

```gdscript

@export var zigzag_amplitude: float = 100.0
@export var zigzag_frequency: float = 2.0
@export var forward_speed: float = 120.0

    var horizontal: float = sin(_elapsed_time * zigzag_frequency) * zigzag_amplitude
    return Vector2(horizontal, forward_speed)
```

**EnemyTank** — медленный, но стреляющий очередями:

```gdscript
# scripts/enemy_tank.gd
extends "res://scripts/enemy_base.gd"

@export var forward_speed: float = 60.0
@export var burst_count: int = 3
@export var burst_interval: float = 0.15
@export var fire_interval: float = 2.5

var _burst_fired: int = 0
var _burst_cooldown: float = 0.0


func move_behavior(_delta: float) -> Vector2:
    return Vector2.ZERO + Vector2.DOWN * forward_speed


func fire_behavior(delta: float) -> void:
    if _burst_fired > 0:
        _burst_cooldown -= delta
        if _burst_cooldown <= 0.0:
            _fire_bullet()
            _burst_fired -= 1
            _burst_cooldown = burst_interval
        return

    _fire_timer -= delta
    if _fire_timer <= 0.0:
        _burst_fired = burst_count
        _burst_cooldown = 0.0
        _fire_timer = fire_interval


func _fire_bullet() -> void:
    var bullet_scene: PackedScene = preload("res://scenes/enemy_bullet.tscn")
    var bullet: Node2D = ObjectPool.get_instance(bullet_scene)
    if bullet and bullet.has_method("activate"):
        var dir: Vector2 = Vector2.DOWN
        if is_instance_valid(get_node_or_null("/root/Main/PlayArea/Player")):
            var player: Node2D = get_node("/root/Main/PlayArea/Player")
            dir = (player.global_position - gun_position.global_position).normalized()
        bullet.activate(gun_position.global_position, dir, 250.0, 1)
```

**EnemyBomber** — сбрасывает мины:

```gdscript
# scripts/enemy_bomber.gd
extends "res://scripts/enemy_base.gd"

@export var forward_speed: float = 80.0
@export var mine_interval: float = 1.5
@export var mine_scene: PackedScene


func move_behavior(_delta: float) -> Vector2:
    # Движется вперёд с лёгким покачиванием
    var wobble: float = sin(_elapsed_time * 3.0) * 30.0
    return Vector2(wobble, forward_speed)


func fire_behavior(delta: float) -> void:
    _fire_timer -= delta
    if _fire_timer <= 0.0:
        _drop_mine()
        _fire_timer = mine_interval


func _drop_mine() -> void:
    if mine_scene == null:
        return
    var mine: Node2D = ObjectPool.get_instance(mine_scene)
    if mine and mine.has_method("activate"):
        mine.activate(gun_position.global_position, Vector2.DOWN, 50.0, 1)
```

**EnemyElite** — круговой паттерн движения:

```gdscript
# scripts/enemy_elite.gd
extends "res://scripts/enemy_base.gd"

@export var circle_radius: float = 80.0
@export var circle_speed: float = 1.5
@export var forward_speed: float = 50.0
@export var fire_interval: float = 0.8

var _center_x: float = 0.0


func activate(pos: Vector2, enemy_data: EnemyData) -> void:
    super.activate(pos, enemy_data)
    _center_x = pos.x


func move_behavior(_delta: float) -> Vector2:
    var target_x: float = _center_x + cos(_elapsed_time * circle_speed) * circle_radius
    var target_y: float = global_position.y + forward_speed * get_physics_process_delta_time()
    var direction: Vector2 = Vector2(target_x - global_position.x, forward_speed)
    return direction
```

<Callout type="info" title="Наследование сцен в Godot">

В Godot наследование сцен работает через `extends "res://path/to/scene.tscn"` или `extends "res://path/to/script.gd"`. Для врагов мы наследуем скрипт: `enemy_fighter.gd` extends `enemy_base.gd`. В редакторе каждая сцена врага (`enemy_fighter.tscn`) наследует `enemy_base.tscn` (New Scene → Inherit Scene), что позволяет добавлять уникальные узлы (дополнительные GunPosition у Bomber, визуальные эффекты у Elite) при сохранении общей структуры.

</Callout>

<Insight title="Template Method vs Composition">

Паттерн Template Method через наследование — не единственный подход. Альтернатива — композиция: EnemyBase содержит `MovementBehavior` и `FireBehavior` как отдельные объекты. Это гибче (можно менять поведение в рантайме), но сложнее в настройке. Для учебного проекта наследование проще и нагляднее, а количество типов врагов ограничено и известно заранее.

</Insight>

## 5.6 Boss — босс с фазами

Boss — самый сложный враг, реализованный через паттерн State. Босс имеет три фазы, каждая из которых определяет уникальные атакующие паттерны и скорость движения. Фаза переключается при достижении порога здоровья — это создаёт драматический момент: босс «разъяряется», начинает двигаться быстрее и стрелять плотнее. Переход между фазами сопровождается визуальными эффектами (вспышка, смена цвета) и звуковым сигналом.

Паттерн State реализован через enum + match — это простой и читаемый подход для ограниченного числа состояний. Каждый блок match инкапсулирует логику одной фазы, что упрощает понимание и модификацию.

Создайте файл `scripts/boss.gd`:

```gdscript
# scripts/boss.gd
extends "res://scripts/enemy_base.gd"

enum Phase {
    PHASE_1,    # 100%–66% здоровья: медленная стрельба, простое движение
    PHASE_2,    # 66%–33% здоровья: веерная стрельба, зигзаг
    PHASE_3,    # 33%–0% здоровья: круговая очередь, быстрое движение
}

@export var phase_1_fire_rate: float = 1.0
@export var phase_2_fire_rate: float = 0.6
@export var phase_3_fire_rate: float = 0.3
@export var phase_2_health_pct: float = 0.66
@export var phase_3_health_pct: float = 0.33

var current_phase: Phase = Phase.PHASE_1
var _phase_transitioning: bool = false
var _pattern_angle: float = 0.0
var _move_target_x: float = 576.0
var _entered_screen: bool = false

@onready var gun_positions: Array[Marker2D] = []

# Предзагруженные сцены
var _enemy_bullet_scene: PackedScene = preload("res://scenes/enemy_bullet.tscn")


func _ready() -> void:
    super._ready()
    # Собираем все GunPosition узлы
    for child in get_children():
        if child is Marker2D and child.name.begins_with("Gun"):
            gun_positions.append(child)


func activate(pos: Vector2, enemy_data: EnemyData) -> void:
    super.activate(pos, enemy_data)
    current_phase = Phase.PHASE_1
    _phase_transitioning = false
    _entered_screen = false
    _move_target_x = 576.0


func move_behavior(delta: float) -> Vector2:
    # Фаза входа — босс плавно въезжает сверху
    if not _entered_screen:
        if global_position.y < 120.0:
            return Vector2.DOWN * 60.0
        _entered_screen = true
        return Vector2.ZERO

    match current_phase:
        Phase.PHASE_1:
            # Медленное горизонтальное перемещение к цели
            var diff_x: float = _move_target_x - global_position.x
            return Vector2(diff_x * 1.5, 0.0)

        Phase.PHASE_2:
            # Зигзаг с ускорением
            var zigzag: float = sin(_elapsed_time * 2.0) * 150.0
            return Vector2(zigzag, sin(_elapsed_time * 0.5) * 20.0)

        Phase.PHASE_3:
            # Быстрое агрессивное движение
            var aggressive: float = sin(_elapsed_time * 3.5) * 200.0
            return Vector2(aggressive, cos(_elapsed_time * 1.5) * 40.0)

    return Vector2.ZERO


func fire_behavior(delta: float) -> void:
    if not _entered_screen:
        return

    _fire_timer -= delta
    if _fire_timer > 0.0:
        return

    match current_phase:
        Phase.PHASE_1:
            _fire_aimed_shot()
            _fire_timer = phase_1_fire_rate

        Phase.PHASE_2:
            _fire_spread_shot()
            _fire_timer = phase_2_fire_rate

        Phase.PHASE_3:
            _fire_circular_burst()
            _fire_timer = phase_3_fire_rate


func take_damage(amount: int) -> void:
    super.take_damage(amount)
    if not _is_active:
        return
    _check_phase_transition()


func _check_phase_transition() -> void:
    if data == null or _phase_transitioning:
        return

    var health_pct: float = float(health) / float(data.max_health)
    var new_phase: Phase = current_phase

    if health_pct <= phase_3_health_pct:
        new_phase = Phase.PHASE_3
    elif health_pct <= phase_2_health_pct:
        new_phase = Phase.PHASE_2

    if new_phase != current_phase:
        _transition_to_phase(new_phase)


func _transition_to_phase(phase: Phase) -> void:
    _phase_transitioning = true
    current_phase = phase

    # Визуальный эффект перехода
    var tween: Tween = create_tween()
    tween.tween_property($Sprite2D, "modulate", Color.RED, 0.1)
    tween.tween_property($Sprite2D, "modulate", Color.WHITE, 0.3)
    tween.tween_callback(func(): _phase_transitioning = false)

    AudioManager.play_sfx("boss_phase")

    # Уведомляем HUD о смене фазы
    GameManager.boss_phase_changed.emit(phase + 1)


func _fire_aimed_shot() -> void:
    if gun_positions.is_empty():
        return
    var gun: Marker2D = gun_positions[0]
    var dir: Vector2 = _get_direction_to_player()
    _spawn_bullet(gun.global_position, dir, 300.0)


func _fire_spread_shot() -> void:
    if gun_positions.is_empty():
        return
    var gun: Marker2D = gun_positions[0]
    var base_dir: Vector2 = _get_direction_to_player()
    var base_angle: float = base_dir.angle()

    for i in range(5):
        var angle_offset: float = deg_to_rad(-20.0 + 10.0 * i)
        var dir: Vector2 = Vector2.from_angle(base_angle + angle_offset)
        _spawn_bullet(gun.global_position, dir, 280.0)


func _fire_circular_burst() -> void:
    var bullet_count: int = 12
    for i in range(bullet_count):
        var angle: float = _pattern_angle + (TAU / bullet_count) * i
        var dir: Vector2 = Vector2.from_angle(angle)
        _spawn_bullet(global_position, dir, 200.0)
    # Сдвигаем паттерн для спирального эффекта
    _pattern_angle += deg_to_rad(15.0)


func _spawn_bullet(pos: Vector2, dir: Vector2, spd: float) -> void:
    var bullet: Node2D = ObjectPool.get_instance(_enemy_bullet_scene)
    if bullet and bullet.has_method("activate"):
        bullet.activate(pos, dir, spd, 1)


func _get_direction_to_player() -> Vector2:
    var player_path: String = "/root/Main/PlayArea/Player"
    if has_node(player_path):
        var player: Node2D = get_node(player_path)
        return (player.global_position - global_position).normalized()
    return Vector2.DOWN


func die() -> void:
    # Босс даёт много очков
    var points: int = data.points if data else 500
    died.emit(points)

    # Серия взрывов для эффектности
    for i in range(5):
        var offset: Vector2 = Vector2(randf_range(-40, 40), randf_range(-40, 40))
        var explosion: Node2D = ObjectPool.get_instance(preload("res://scenes/explosion.tscn"))
        if explosion:
            explosion.global_position = global_position + offset
        await get_tree().create_timer(0.15).timeout

    AudioManager.play_sfx("boss_defeat")
    _return_to_pool()
```

<Callout type="warning" title="await в die() — будьте осторожны">

Метод `die()` у босса использует `await` для серии взрывов. Пока выполняется `await`, босс всё ещё находится в дереве. Убедитесь, что `_is_active = false` установлен до первого `await`, чтобы босс не получал урон и не двигался во время анимации смерти. Если WaveManager проверяет `enemies_alive` сразу при сигнале `died`, взрывы будут воспроизводиться параллельно с переходом к следующей волне — это нормально и даже желательно.

</Callout>

<Insight title="Спиральный паттерн в PHASE_3">

Переменная `_pattern_angle` увеличивается после каждого залпа, создавая эффект «спирали» — каждый следующий круг пуль повёрнут относительно предыдущего. Это классический паттерн из bullet-hell игр, который выглядит впечатляюще и при этом оставляет «окна» для манёвра, потому что пули распределены равномерно. Угол сдвига в 15° подобран экспериментально: при 12 пулях в круге (шаг 30°) сдвиг в 15° означает, что пули следующего залпа летят между пулями предыдущего.

</Insight>

## 5.7 WaveManager — менеджер волн

WaveManager управляет ритмом игры, определяя, когда и какие враги появляются. Он реализован как конечный автомат (FSM) с тремя состояниями: Idle (ожидание перед волной), Spawning (активный спавн врагов из очереди), Active (все враги заспавнены, ждём их уничтожения). Состояния определяют, что делает WaveManager в `_process()`: в Idle он считает таймер задержки, в Spawning — извлекает врагов из очереди и размещает их на экране, в Active — ждёт, пока последний враг не будет уничтожен.

WaveManager парсит `WaveData` — массив `SpawnEntry`, каждая из которых описывает тип врага, количество и задержку между спавнами. Это позволяет геймдизайнеру создавать волны любой сложности, просто редактируя `.tres`-файлы.

Создайте файл `scripts/wave_manager.gd`:

```gdscript
# scripts/wave_manager.gd
extends Node

signal wave_started(wave_number: int)
signal wave_completed(wave_number: int)
signal all_waves_completed

enum State { IDLE, SPAWNING, ACTIVE }

@export var waves: Array[WaveData] = []
@export var delay_between_waves: float = 3.0
@export var boss_wave_interval: int = 5  # Босс каждые 5 волн

var current_wave: int = 0
var enemies_alive: int = 0
var state: State = State.IDLE

var _spawn_queue: Array[SpawnEntry] = []
var _spawn_timer: float = 0.0
var _idle_timer: float = 0.0
var _is_boss_wave: bool = false

# Границы экрана для спавна
var _screen_rect: Rect2 = Rect2(0, 0, 1152, 648)


func _ready() -> void:
    _idle_timer = 1.0  # Короткая пауза перед первой волной


func _process(delta: float) -> void:
    match state:
        State.IDLE:
            _process_idle(delta)
        State.SPAWNING:
            _process_spawning(delta)
        State.ACTIVE:
            _process_active(delta)


func _process_idle(delta: float) -> void:
    _idle_timer -= delta
    if _idle_timer <= 0.0:
        start_next_wave()


func _process_spawning(delta: float) -> void:
    _spawn_timer -= delta
    if _spawn_timer > 0.0:
        return

    if _spawn_queue.is_empty():
        state = State.ACTIVE
        return

    _spawn_next_enemy()


func _process_active(_delta: float) -> void:
    # Ожидание уничтожения всех врагов
    # enemies_alive обновляется через _on_enemy_died()
    if enemies_alive <= 0:
        _complete_current_wave()


func start_next_wave() -> void:
    if current_wave >= waves.size():
        all_waves_completed.emit()
        state = State.IDLE
        return

    _is_boss_wave = (current_wave + 1) % boss_wave_interval == 0 and current_wave > 0
    var wave_data: WaveData = waves[current_wave]

    _build_spawn_queue(wave_data)
    state = State.SPAWNING
    _spawn_timer = 0.0

    wave_started.emit(current_wave + 1)
    AudioManager.play_sfx("wave_start")


func _build_spawn_queue(wave: WaveData) -> void:
    _spawn_queue.clear()
    for entry: SpawnEntry in wave.spawn_entries:
        for i in range(entry.count):
            _spawn_queue.append(entry)


func _spawn_next_enemy() -> void:
    var entry: SpawnEntry = _spawn_queue.pop_front()
    var enemy: Node2D = ObjectPool.get_instance(entry.enemy_scene)
    if enemy == null:
        return

    # Позиция спавна — случайная X, за верхним краем экрана
    var spawn_x: float = randf_range(_screen_rect.position.x + 50, _screen_rect.end.x - 50)
    var spawn_y: float = _screen_rect.position.y - 50
    var spawn_pos: Vector2 = Vector2(spawn_x, spawn_y)

    if enemy.has_method("activate"):
        enemy.activate(spawn_pos, entry.enemy_data)

    # Подключаем сигнал смерти
    if enemy.has_signal("died"):
        if not enemy.died.is_connected(_on_enemy_died):
            enemy.died.connect(_on_enemy_died)

    enemies_alive += 1
    _spawn_timer = entry.delay


func _on_enemy_died(points: int) -> void:
    enemies_alive -= 1
    GameManager.add_score(points)


func _complete_current_wave() -> void:
    wave_completed.emit(current_wave + 1)
    current_wave += 1
    state = State.IDLE
    _idle_timer = delay_between_waves


func reset() -> void:
    current_wave = 0
    enemies_alive = 0
    _spawn_queue.clear()
    state = State.IDLE
    _idle_timer = 2.0


func get_wave_number() -> int:
    return current_wave + 1
```

<Callout type="info" title="Разбор потока спавна">

1. **IDLE**: WaveManager ждёт `delay_between_waves` секунд. Таймер показывает «Волна N через X...»
2. **SPAWNING**: `_spawn_queue` содержит `SpawnEntry` для каждого врага в волне. Каждые `entry.delay` секунд из очереди извлекается следующая запись и создаётся враг.
3. **ACTIVE**: Все враги заспавнены, но ещё живы. WaveManager ждёт, пока `enemies_alive` не станет 0.
4. При `enemies_alive == 0` вызывается `_complete_current_wave()`, испускается `wave_completed`, и WaveManager переходит в IDLE с таймером перед следующей волной.

</Callout>

<Insight title="Почему enemies_alive — отдельная переменная, а не get_child_count()?">

Можно было бы считать живых врагов через `EnemyContainer.get_child_count()`, но это ненадёжно: в контейнере могут быть неактивные объекты из пула, которые всё ещё являются дочерними узлами. Переменная `enemies_alive` считает только фактически активных врагов, что точнее и не зависит от реализации пула. Кроме того, `enemies_alive` обновляется мгновенно при сигнале `died`, а `get_child_count()` — только после физического удаления узла из дерева.

</Insight>

## 5.8 Pickup — бонусы

Pickup — это Area2D-объект, который появляется на месте уничтоженного врага и предоставляет игроку бонус при подборе. Бонусы реализованы через enum `PickupType`, что позволяет легко добавлять новые типы без изменения архитектуры. Каждый бонус имеет анимацию покачивания (bobbing), которая привлекает внимание игрока и делает игровой мир более живым.

Создайте файл `scripts/pickup.gd`:

```gdscript
# scripts/pickup.gd
extends Area2D

enum PickupType {
    HEALTH,     # Восстановление здоровья
    SHIELD,     # Временный щит (3 попадания)
    WEAPON,     # Улучшение оружия
    SCORE,      # Бонусные очки
}

@export var pickup_type: PickupType = PickupType.HEALTH
@export var value: int = 1
@export var fall_speed: float = 60.0
@export var bob_amplitude: float = 5.0
@export var bob_frequency: float = 3.0
@export var lifetime: float = 8.0

var _is_active: bool = false
var _elapsed: float = 0.0
var _base_y: float = 0.0

@onready var sprite: Sprite2D = $Sprite2D
@onready var collision_shape: CollisionShape2D = $CollisionShape2D
@onready var animation_player: AnimationPlayer = $AnimationPlayer


func _physics_process(delta: float) -> void:
    if not _is_active:
        return

    _elapsed += delta

    # Медленное падение + покачивание
    _base_y += fall_speed * delta
    var bob_offset: float = sin(_elapsed * bob_frequency) * bob_amplitude
    global_position.y = _base_y + bob_offset

    # Автоудаление по истечении времени
    if _elapsed >= lifetime:
        _return_to_pool()


func activate(pos: Vector2, type: PickupType = PickupType.HEALTH, val: int = 1) -> void:
    global_position = pos
    _base_y = pos.y
    pickup_type = type
    value = val
    _is_active = true
    _elapsed = 0.0
    visible = true
    if collision_shape:
        collision_shape.set_deferred("disabled", false)
    if animation_player:
        animation_player.play("bob")
    _update_visual()


func collect(player: Node) -> void:
    if not _is_active:
        return

    match pickup_type:
        PickupType.HEALTH:
            if player.has_method("heal"):
                player.heal(value)
            AudioManager.play_sfx("pickup_health")

        PickupType.SHIELD:
            if player.has_method("activate_shield"):
                player.activate_shield(3)  # 3 попадания
            AudioManager.play_sfx("pickup_shield")

        PickupType.WEAPON:
            if player.has_method("add_weapon"):
                var weapon: WeaponData = _get_random_weapon()
                if weapon:
                    player.add_weapon(weapon)
            AudioManager.play_sfx("pickup_weapon")

        PickupType.SCORE:
            if GameManager:
                GameManager.add_score(value * 50)
            AudioManager.play_sfx("pickup_score")

    _return_to_pool()


func _update_visual() -> void:
    # В реальном проекте — разные спрайты для разных типов
    # Здесь используем цветовую индикацию
    if not sprite:
        return
    match pickup_type:
        PickupType.HEALTH:
            sprite.modulate = Color.GREEN
        PickupType.SHIELD:
            sprite.modulate = Color.CYAN
        PickupType.WEAPON:
            sprite.modulate = Color.ORANGE
        PickupType.SCORE:
            sprite.modulate = Color.GOLD


func _get_random_weapon() -> WeaponData:
    var weapons: Array[WeaponData] = [
        preload("res://resources/weapons/machinegun.tres"),
        preload("res://resources/weapons/spreadgun.tres"),
    ]
    if weapons.is_empty():
        return null
    return weapons.pick_random()


func _return_to_pool() -> void:
    _is_active = false
    visible = false
    if collision_shape:
        collision_shape.set_deferred("disabled", true)
    if animation_player:
        animation_player.stop()
    if ObjectPool:
        ObjectPool.release(self)
```

<Callout type="tip" title="Случайный дроп — настройка вероятностей">

Метод `_try_spawn_pickup()` в `enemy_base.gd` использует `data.drop_chance` для определения вероятности выпадения бонуса. В EnemyData можно настроить:

- **Fighter**: `drop_chance = 0.1` (10% — редкий дроп)
- **Tank**: `drop_chance = 0.25` (25% — средний дроп)
- **Bomber**: `drop_chance = 0.2` (20% — средний дроп)
- **Elite**: `drop_chance = 0.4` (40% — частый дроп)

Тип бонуса определяется случайно в момент активации pickup. Вероятности по типам: HEALTH 40%, SCORE 30%, WEAPON 20%, SHIELD 10%. Более ценные бонусы выпадают реже — это основа баланса.

</Callout>

## 5.9 HUD — интерфейс

HUD (Heads-Up Display) — это CanvasLayer, который отрисовывается поверх игровой сцены и показывает актуальную информацию о состоянии игры. Ключевой принцип HUD: он управляется исключительно сигналами и никогда не опрашивает менеджеры напрямую. Когда GameManager испускает `score_changed`, HUD обновляет счёт. Когда WaveManager испускает `wave_started`, HUD показывает номер волны. Это слабая связанность в действии: HUD не знает о внутренней структуре менеджеров — он реагирует на события.

Создайте файл `scripts/hud.gd`:

```gdscript
# scripts/hud.gd
extends CanvasLayer

@onready var score_label: Label = %ScoreLabel
@onready var health_bar: TextureProgressBar = %HealthBar
@onready var wave_label: Label = %WaveLabel
@onready var combo_label: Label = %ComboLabel
@onready var boss_health_bar: TextureProgressBar = %BossHealthBar
@onready var boss_name_label: Label = %BossNameLabel
@onready var message_label: Label = %MessageLabel

var _message_tween: Tween = null


func _ready() -> void:
    # Подключаем сигналы GameManager
    if GameManager:
        GameManager.score_changed.connect(_on_score_changed)
        GameManager.combo_changed.connect(_on_combo_changed)

    # Подключаем сигналы WaveManager
    if WaveManager:
        WaveManager.wave_started.connect(_on_wave_started)
        WaveManager.wave_completed.connect(_on_wave_completed)

    # Подключаем сигналы Player (через отложенный вызов, т.к. Player может ещё не быть)
    call_deferred("_connect_player_signals")

    # Скрываем босс-бар
    _hide_boss_bar()

    # Начальные значения
    score_label.text = "Очки: 0"
    combo_label.text = ""
    wave_label.text = ""


func _connect_player_signals() -> void:
    var player: Node = get_node_or_null("/root/Main/PlayArea/Player")
    if player:
        if player.has_signal("health_changed"):
            player.health_changed.connect(_on_health_changed)
        if player.has_signal("died"):
            player.died.connect(_on_player_died)
    if GameManager and GameManager.has_signal("boss_phase_changed"):
        GameManager.boss_phase_changed.connect(_on_boss_phase_changed)


func _on_score_changed(new_score: int) -> void:
    score_label.text = "Очки: %d" % new_score
    # Краткая анимация увеличения
    _pulse_label(score_label)


func _on_combo_changed(multiplier: float) -> void:
    if multiplier > 1.0:
        combo_label.text = "×%.1f" % multiplier
        combo_label.modulate = Color.YELLOW if multiplier < 3.0 else Color.RED
    else:
        combo_label.text = ""


func _on_health_changed(current: int, maximum: int) -> void:
    if health_bar:
        health_bar.value = (float(current) / float(maximum)) * 100.0


func _on_wave_started(wave_number: int) -> void:
    wave_label.text = "Волна %d" % wave_number

    if WaveManager and WaveManager._is_boss_wave:
        show_message("⚠ БОСС! ⚠", 3.0)
        _show_boss_bar()
    else:
        show_message("Волна %d" % wave_number, 2.0)


func _on_wave_completed(wave_number: int) -> void:
    show_message("Волна %d пройдена!" % wave_number, 2.0)
    _hide_boss_bar()


func _on_player_died() -> void:
    show_message("GAME OVER", 0)  # 0 = не скрывать


func _on_boss_phase_changed(phase: int) -> void:
    show_message("Фаза босса %d!" % phase, 1.5)


func _on_boss_health_changed(current: int, maximum: int) -> void:
    if boss_health_bar:
        boss_health_bar.value = (float(current) / float(maximum)) * 100.0


func show_message(text: String, duration: float = 2.0) -> void:
    message_label.text = text
    message_label.modulate.a = 1.0
    message_label.visible = true

    # Отменяем предыдущую анимацию
    if _message_tween and _message_tween.is_valid():
        _message_tween.kill()

    if duration > 0.0:
        _message_tween = create_tween()
        _message_tween.tween_interval(duration)
        _message_tween.tween_property(message_label, "modulate:a", 0.0, 0.5)
        _message_tween.tween_callback(func(): message_label.visible = false)


func _show_boss_bar() -> void:
    boss_health_bar.visible = true
    boss_name_label.visible = true
    boss_name_label.text = "БОСС"
    # Подключаем к здоровью босса
    call_deferred("_connect_boss_signals")


func _hide_boss_bar() -> void:
    boss_health_bar.visible = false
    boss_name_label.visible = false


func _connect_boss_signals() -> void:
    # Ищем босса и подключаем его сигнал health_changed
    var boss: Node = get_node_or_null("/root/Main/PlayArea/EnemyContainer/Boss")
    if boss and boss.has_signal("health_changed"):
        boss.health_changed.connect(_on_boss_health_changed)


func _pulse_label(label: Label) -> void:
    var tween: Tween = create_tween()
    tween.tween_property(label, "scale", Vector2(1.2, 1.2), 0.1)
    tween.tween_property(label, "scale", Vector2.ONE, 0.15)
```

<Callout type="info" title="CanvasLayer — зачем он нужен?">

HUD использует CanvasLayer, чтобы гарантировать, что элементы интерфейса не двигаются вместе с камерой. Без CanvasLayer, если камера следит за игроком, все Label и ProgressBar сдвигались бы вместе с миром. CanvasLayer создаёт отдельный слой рендеринга, который привязан к экрану, а не к мировой системе координат. Это стандартный подход для интерфейсов в Godot.

</Callout>

<Insight title="Уникальные имена с % и @onready">

Символ `%` перед именем узла (например, `%ScoreLabel`) — это синтаксис уникальных имён Godot. В редакторе кликните правой кнопкой на узле и выберите **Access as Unique Name**. Это позволяет обращаться к узлу напрямую через `%Name`, не указывая полный путь. Если вы переставите HUDLabel в другой контейнер, `%ScoreLabel` продолжит работать — в отличие от `$TopBar/HBoxContainer/ScoreLabel`, который сломается при любой реорганизации дерева.

</Insight>

## 5.10 GameManager — игровой менеджер

GameManager — это центральный менеджер игры, отвечающий за счёт, комбо-систему, паузу и общий поток игры (старт, game over, рестарт). Он является Autoload-синглтоном, что обеспечивает глобальную доступность из любого скрипта. GameManager оперирует только числами и сигналами — он ничего не знает о визуале, сценах или вводе.

Комбо-система работает по принципу: каждое уничтожение врага увеличивает множитель (до максимума 4×), а промах (снаряд вылетел за экран без попадания) или длительное отсутствие убийств сбрасывает его до 1×. Это создаёт стимул стрелять точно и агрессивно — награда за мастерство.

Создайте файл `scripts/game_manager.gd`:

```gdscript
# scripts/game_manager.gd
extends Node

signal score_changed(new_score: int)
signal combo_changed(multiplier: float)
signal game_over
signal game_restarted
signal boss_phase_changed(phase: int)
signal paused_changed(is_paused: bool)

@export var max_combo: float = 4.0
@export var combo_decay_time: float = 3.0  # Секунд до сброса комбо

var score: int = 0
var combo: float = 1.0
var _combo_timer: float = 0.0
var _is_paused: bool = false
var _is_game_over: bool = false
var _high_score: int = 0


func _ready() -> void:
    _load_high_score()


func _process(delta: float) -> void:
    if _is_game_over or _is_paused:
        return
    # Деградация комбо со временем
    if combo > 1.0:
        _combo_timer -= delta
        if _combo_timer <= 0.0:
            _reset_combo()


func add_score(points: int) -> void:
    if _is_game_over:
        return

    var multiplied: int = int(points * combo)
    score += multiplied
    score_changed.emit(score)

    # Увеличиваем комбо
    combo = minf(combo + 0.25, max_combo)
    _combo_timer = combo_decay_time
    combo_changed.emit(combo)


func _reset_combo() -> void:
    combo = 1.0
    _combo_timer = 0.0
    combo_changed.emit(combo)


func miss_shot() -> void:
    """Вызывается, когда снаряд вылетел за экран без попадания."""
    if combo > 1.0:
        combo = maxf(combo - 0.5, 1.0)
        combo_changed.emit(combo)


func trigger_game_over() -> void:
    _is_game_over = true
    if score > _high_score:
        _high_score = score
        _save_high_score()
    game_over.emit()


func restart_game() -> void:
    score = 0
    combo = 1.0
    _combo_timer = 0.0
    _is_game_over = false
    _is_paused = false
    score_changed.emit(score)
    combo_changed.emit(combo)
    game_restarted.emit()


func toggle_pause() -> void:
    if _is_game_over:
        return
    _is_paused = not _is_paused
    get_tree().paused = _is_paused
    paused_changed.emit(_is_paused)


func is_paused() -> bool:
    return _is_paused


func is_game_over() -> bool:
    return _is_game_over


func get_high_score() -> int:
    return _high_score


func _load_high_score() -> void:
    var save_path: String = "user://highscore.save"
    if FileAccess.file_exists(save_path):
        var file: FileAccess = FileAccess.open(save_path, FileAccess.READ)
        if file:
            _high_score = int(file.get_line())
            file.close()


func _save_high_score() -> void:
    var save_path: String = "user://highscore.save"
    var file: FileAccess = FileAccess.open(save_path, FileAccess.WRITE)
    if file:
        file.store_line(str(_high_score))
        file.close()
```

<Callout type="danger" title="Порядок Autoload-ов">

Добавьте менеджеры в **Project → Project Settings → Autoload** в следующем порядке:

1. **ObjectPool** (`scripts/object_pool.gd`) — первым, потому что все остальные менеджеры могут использовать пул
2. **GameManager** (`scripts/game_manager.gd`) — второй, потому что WaveManager и AudioManager ссылаются на него
3. **WaveManager** (`scripts/wave_manager.gd`) — третий, зависит от GameManager
4. **AudioManager** (`scripts/audio_manager.gd`) — последний, зависит от остальных

Порядок критичен: Autoload-узлы инициализируются сверху вниз. Если WaveManager загрузится раньше GameManager, обращение к `GameManager.add_score()` в его `_ready()` вызовет ошибку.

</Callout>

Теперь свяжем все компоненты в `scripts/main.gd`:

```gdscript
# scripts/main.gd
extends Node2D

@onready var player: CharacterBody2D = %Player
@onready var enemy_container: Node2D = $PlayArea/EnemyContainer
@onready var bullet_container: Node2D = $PlayArea/BulletContainer
@onready var pickup_container: Node2D = $PlayArea/PickupContainer
@onready var explosion_container: Node2D = $ExplosionContainer
@onready var hud: CanvasLayer = $HUD

var _screen_rect: Rect2 = Rect2(0, 0, 1152, 648)


func _ready() -> void:
    # Передаём границы экрана игроку
    if player and player.has_method("_screen_rect"):
        player._screen_rect = _screen_rect

    # Подключаем сигнал смерти игрока к Game Over
    if player and player.has_signal("died"):
        player.died.connect(_on_player_died)

    # Подключаем сигналы WaveManager
    if WaveManager:
        WaveManager.all_waves_completed.connect(_on_all_waves_completed)

    # Подключаем сигналы GameManager
    if GameManager:
        GameManager.game_restarted.connect(_on_game_restarted)


func _on_player_died() -> void:
    GameManager.trigger_game_over()


func _on_all_waves_completed() -> void:
    # Победа!
    GameManager.add_score(1000)  # Бонус за прохождение
    hud.show_message("ПОБЕДА!", 0)


func _on_game_restarted() -> void:
    # Перезапуск — пересоздаём сцену
    get_tree().paused = false
    get_tree().reload_current_scene()


func _input(event: InputEvent) -> void:
    if event.is_action_pressed("pause"):
        GameManager.toggle_pause()
```

<Callout type="info" title="Итоговая архитектура связей">

Полный поток данных в собранной игре:

1. **WaveManager** спавнит врагов через **ObjectPool** и подключает их сигнал `died`
2. **Player** стреляет снарядами через **ObjectPool**, снаряды летят и попадают во врагов
3. **Враг** получает урон → умирает → испускает `died` → **WaveManager** передаёт очки в **GameManager**
4. **GameManager** обновляет счёт и комбо → испускает сигналы → **HUD** обновляет интерфейс
5. **Pickup** подбирается игроком → лечит / даёт щит / улучшает оружие
6. **Boss** меняет фазу при пороге здоровья → **GameManager** → **HUD** показывает уведомление
7. **Player** умирает → **GameManager** вызывает `trigger_game_over()` → **HUD** показывает «GAME OVER»

Ни один компонент не знает о внутреннем устройстве другого. Все взаимодействия — через сигналы и публичные методы. Это делает систему расширяемой: добавление новой механики (например, Achievement-системы) требует только подключения новых слушателей к существующим сигналам.

</Callout>

В следующей главе (Глава 6: Шейдеры и VFX) мы добавим визуальные эффекты: взрывы с шейдерами, звёздное поле с параллаксом, эффекты попадания и подсветку щита. Все эти эффекты будут использовать уже созданную инфраструктуру: ObjectPool для управления частицами, AudioManager для озвучивания и GameManager для связи с логикой игры.
