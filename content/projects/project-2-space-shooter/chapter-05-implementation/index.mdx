## 5.1 WeaponData — модель данных оружия

WeaponData — это Resource, который описывает все параметры оружия. Использование Resource для данных оружия — это ключевой архитектурный решение: оно позволяет создавать новые виды оружия без написания кода, просто создавая новые `.tres`-файлы в редакторе.
