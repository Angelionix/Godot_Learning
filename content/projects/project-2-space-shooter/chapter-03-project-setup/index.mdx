## 3.1 Создание проекта

Создайте новый проект Godot 4.3+ с рендерером Compatibility. Этот рендерер оптимизирован для 2D-игр и обеспечивает максимальную совместимость с различными устройствами. В отличие от Forward+ и Mobile, Compatibility поддерживает все 2D-функции без ограничений и обеспечивает стабильную производительность даже на слабом оборудовании.

При создании проекта укажите разрешение окна 480x720 (портретная ориентация, типичная для вертикальных шутеров) и установите режим растяжения `canvas_items` с аспектом `keep`. Это гарантирует, что игровая область будет масштабироваться пропорционально на экранах любого размера без искажений.

## 3.2 Настройка слоёв столкновений

Откройте Project → Project Settings → Layer Names → 2D Physics и задайте следующие имена для первых пяти слоёв:

- Слой 1: `Player`
- Слой 2: `PlayerBullet`
- Слой 3: `Enemy`
- Слой 4: `EnemyBullet`
- Слой 5: `Pickup`

Эти имена будут отображаться в инспекторе при настройке CollisionShape2D и Area2D, что значительно упрощает конфигурацию. Без имён вы видите лишь номера битов (1, 2, 4, 8, 16), что легко приводит к ошибкам.

## 3.3 Настройка действий ввода

Откройте Project → Project Settings → Input Map и добавьте следующие действия:

| Действие | Клавиша 1 | Клавиша 2 |
|---|---|---|
| move_up | W | Стрелка вверх |
| move_down | S | Стрелка вниз |
| move_left | A | Стрелка влево |
| move_right | D | Стрелка вправо |
| fire | Space | Левая кнопка мыши |
| bomb | Shift | — |

Для каждого действия добавьте обе клавиши, чтобы игрок мог использовать либо WASD, либо стрелки. Действие `fire` также привязано к левой кнопке мыши — это стандарт для аркадных шутеров, где мышь может использоваться для позиционирования.

## 3.4 Настройка Autoload

Autoload — это механизм Godot для создания глобальных объектов, которые существуют на протяжении всего жизненного цикла игры. Порядок добавления важен: если менеджер зависит от другого менеджера, он должен быть добавлен позже. Наш порядок:

1. **GameManager** (`scripts/game_manager.gd`) — не зависит от других менеджеров
2. **ObjectPool** (`scripts/object_pool.gd`) — не зависит от других менеджеров
3. **WaveManager** (`scripts/wave_manager.gd`) — зависит от ObjectPool
4. **AudioManager** (`scripts/audio_manager.gd`) — не зависит от других менеджеров

Для добавления Autoload: Project → Project Settings → Autoload → выберите скрипт → задайте имя (GameManager, ObjectPool, WaveManager, AudioManager) → нажмите Add. Убедитесь, что флаг Enabled установлен для всех четырёх менеджеров.
